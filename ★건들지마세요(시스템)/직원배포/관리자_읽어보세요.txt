[ 직원 배포용 — 관리자 안내 ]

■ 직원에게 보낼 것 = 이 폴더의  "4XR_시작.bat"  파일 하나

  (메일 첨부 · USB · 회사 공유폴더 \\192.168.4.200 중 편한 방법)


■ 직원이 하는 것 (딱 3가지)

  0) 코워크(Cowork) 앱 설치 · 로그인   ← 평소 작업하는 채팅 앱 (한 번)
  1) 받은  4XR_시작.bat  더블클릭
       - "예" (관리자 권한) 한 번
       - 이름 입력 (예: 황다빈)
       - GitHub 로그인 창이 뜨면 회사 아이디로 로그인 (한 번)
       - 알아서 설치 · 폴더 받기 · 자동동기화 설정까지 끝
  2) 코워크에서  문서\4XR_기획전  폴더를 열고 채팅으로 작업

  → 이후 작업기록은 30분마다 자동으로 회사(내 옵시디언)로 올라옵니다.
    GitHub Desktop · 옵시디언 · 여러 설치파일 필요 없습니다.


■ 로그인 관련

  - 직원은 clone 시 "회사 GitHub 아이디" 로 한 번 로그인합니다.
    아이디/비번을 알려주거나, 관리자가 그 PC에서 대신 로그인해 주세요.
  - 로그인 정보를 직원에게 주기 싫으면, 관리자가 각 PC에서
    4XR_시작.bat 를 직접 한 번 돌려주면 됩니다.


■ 주의

  - "4XR_시작.bat" 안에 회사 저장소 주소가 들어 있습니다
    (github.com/4xrcompany-rgb/exhibitions). 저장소 이름이 바뀌면 이 파일도 고쳐야 합니다.
  - 이 파일은 배포 후 테스트한 뒤 뿌리세요. (PC 1대에서 먼저 확인)
