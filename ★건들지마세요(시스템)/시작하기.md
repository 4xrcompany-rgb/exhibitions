# 새 컴퓨터에서 시작하기 — 클로드 코드

이 폴더 하나만 옮기면 됩니다. 순서대로 20분이면 끝납니다.

---

## 0. 이 폴더에 뭐가 있나

```
★4XR_기획전_자동화/
├─ CLAUDE.md          ← 항상 지킬 규칙. 클로드가 매번 자동으로 읽습니다
├─ .mcp.json          ← 피그마 · 힉스필드 연결 설정
├─ .claude/skills/gihoekjeon-automation-system/
│  ├─ SKILL.md        ← 작업 순서·규칙 본문
│  ├─ references/     ← 상세 문서 6개 (필요할 때만 읽음)
│  └─ scripts/        ← 실행 스크립트 6개
├─ 참고/
│  └─ 기획전_작업_자동화_마스터.md   ← 전체 기록. 스크립트 전문까지 들어있음
└─ 시작하기.md        ← 이 파일
```

**여기에 기획전 작업 폴더를 같이 넣으시면 됩니다.**

```
★4XR_기획전_자동화/
└─ 기획전_제작/
   └─ 하프데이/       ← 지금 D:\김솔\4XR\★AI 자동화\기획전_제작\하프데이 통째로
```

## 1. 새 컴퓨터에 설치할 것

| | 확인 방법 |
|---|---|
| **Node.js** (18 이상) | `node -v` |
| **Python** (3.10 이상) | `python --version` |
| **클로드 코드** | `npm install -g @anthropic-ai/claude-code` 후 `claude --version` |

파이썬 패키지도 한 번만 설치합니다.

```
pip install openpyxl pillow requests beautifulsoup4 numpy scipy
```

배너를 HTML→JPG 로 뽑을 때 쓰는 브라우저도 한 번만.

```
npm install playwright
npx playwright install chromium
```

## 2. 압축 풀기

zip 파일을 새 컴퓨터로 보내고, **거기서** 압축을 풉니다.

```
D:\김솔\4XR\★AI 자동화\기획전\   ← 여기에 압축 풀기
결과:  D:\김솔\4XR\★AI 자동화\기획전\★4XR_기획전_자동화\
```

풀어놓은 폴더를 탐색기로 드래그해 옮기지 마세요. `.claude` 같은 숨은 폴더가 빠집니다.
**zip 을 옮기고 거기서 푸는 것**이 안전합니다.

## 3. 실행

```
cd D:\김솔\4XR\★AI 자동화\기획전\★4XR_기획전_자동화
claude
```

처음 한 번은 로그인 창이 뜹니다.
그리고 **「이 폴더를 신뢰하시겠습니까」** 를 묻습니다. **예**를 눌러야 스킬이 켜집니다.

## 4. 피그마 · 힉스필드 연결

`.mcp.json` 이 이미 들어 있어서, 클로드 코드를 켜면 **「프로젝트 MCP 서버를 승인하시겠습니까」**
를 묻습니다. 승인하면 됩니다.

그다음 세션 안에서

```
/mcp
```

를 치면 목록이 나옵니다. `figma` · `higgsfield` 를 각각 골라 **로그인(Authenticate)** 합니다.
브라우저가 열리고, 로그인하면 끝입니다.

| 서버 | 주소 |
|---|---|
| 피그마 | `https://mcp.figma.com/mcp` |
| 힉스필드 | `https://mcp.higgsfield.ai/mcp` |

**피그마는 Full seat 계정으로 로그인해야 합니다.** View seat 은 편집이 안 됩니다.

승인 창이 안 떴다면 직접 넣어도 됩니다.

```
claude mcp add --transport http --scope project figma https://mcp.figma.com/mcp
claude mcp add --transport http --scope project higgsfield https://mcp.higgsfield.ai/mcp
claude mcp list
```

## 5. 잘 됐는지 확인

클로드 코드 안에서 `/` 를 치면 목록이 뜹니다.
**`gihoekjeon-automation-system`** 이 보이면 스킬이 잡힌 겁니다.

그다음 이렇게 물어보세요.

```
기획전 작업 규칙 요약해줘
```

폴더 규격·⓪~⑥ 순서·주의사항이 나오면 정상입니다.

`/context` 를 치면 `CLAUDE.md` 가 읽혔는지도 볼 수 있습니다.

## 6. 실제 작업 시작

```
D:\김솔\4XR\★AI 자동화\기획전\★4XR_기획전_자동화\기획전_제작\<새 기획전> 폴더에서 작업 시작할게
```

이렇게 폴더를 알려주면 스킬의 고정 순서대로 진행합니다.

```
⓪ 환경 점검
① 작업 폴더 받기
② 참고링크 분해
③ 구성표 엑셀 + 소재 폴더 생성   ← 여기서 멈춤
④ 티그린님이 구성표 채우기
⑤ "엑셀 반영해줘" → 기획전 HTML
⑥ "배너 만들어줘" → 배너 7장
```

## 클라우드에서 쓸 때와 달라지는 점

| | 지금(클라우드) | 클로드 코드(내 컴퓨터) |
|---|---|---|
| 파일 접근 | 폴더를 연결해야 함 | **내 디스크를 그대로 읽고 씀** |
| 몰 이미지·피그마 업로드 | 자주 막힘 (403) | **안 막힘** |
| 완성 파일 전달 | 채팅으로 받아서 저장 | **바로 폴더에 저장됨** |
| 힉스필드 이미지 다운로드 | 우회 필요 | **바로 됨** |

**스킬 §0 의 「차단 우회」 절차가 대부분 필요 없어집니다.** 그대로 두면 됩니다 —
점검만 하고 통과하면 넘어갑니다.

## 막히면

| 증상 | 해결 |
|---|---|
| `/` 목록에 스킬이 안 보임 | `.claude` 폴더가 복사됐는지 확인 (숨긴 항목 보기) |
| 스킬은 보이는데 규칙을 안 지킴 | `CLAUDE.md` 가 폴더 최상단에 있는지 확인. `/context` 로 확인 |
| `/mcp` 에 서버가 없음 | `.mcp.json` 이 복사됐는지 확인 → `claude mcp list` |
| 피그마 편집이 안 됨 | View seat 로 로그인된 것. Full seat 계정으로 다시 로그인 |
| 엑셀 읽기 실패 | 엑셀이 열려 있으면 못 읽습니다. 닫고 다시 |
| 배너 캡처가 안 됨 | `npx playwright install chromium` 다시 실행 |
