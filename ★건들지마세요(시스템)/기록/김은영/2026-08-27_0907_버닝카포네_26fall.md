## 💡 개선 요청 (중앙에 전달)

- **정용진님이 남긴 「몰 전역 리셋 재현」 요청이 이번에도 그대로 재현됨.** 재현본에 몰 전역값이 빠져
  `line-height`·`letter-spacing`·`text-align` 이 전부 어긋났다(초기 불일치 36항목 → 전역값 넣자 12항목).
  **스킬 §5-A 에 아래 실측 블록을 고정 스니펫으로 넣을 것을 제안**한다.

  ```css
  /* 4XR 몰 전역 리셋 — 재현본에 반드시 선행 삽입 */
  *{margin:0;padding:0}
  body{font-family:Arial,sans-serif;font-size:14px;line-height:1;color:#666}
  h1~h6,p,ul,ol,li,form,input,textarea,button{margin:0;padding:0;line-height:1;font-family:inherit}
  ul,ol,li{list-style:none}  img{border:0;vertical-align:top}
  a{color:#666;text-decoration:none;vertical-align:top}
  button{text-align:center;color:#000;background:none;border:0}
  /* ★ 자간이 도메인별로 다르다 (실측) */
  *{letter-spacing:-0.025em}                         /* www.4xr.co.kr (PC) */
  @media(max-width:768px){ *{letter-spacing:-0.03em} } /* m.4xr.co.kr */
  /* ★ PC 는 .cont 가 가운데 정렬 */
  .magazine_view .cont{text-align:center}
  @media(max-width:768px){ .magazine_view .cont{text-align:start} }
  ```
- 모바일 캔버스가 **750px 고정**(`viewport width=750`)이라는 점도 명시 필요.
  스킬 §1-②(6) 「모바일 텍스트 최소 25px」은 이 750 캔버스 기준이어야 뜻이 통한다
