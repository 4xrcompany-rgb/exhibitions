## ✅ 잘된 점

- 커스텀 fragment(§1-④ A): 히어로(KV) + 카테고리 탭(OUTER/TOP/PANTS/ACC, sticky·흰색) + 상품 그리드 5열. 상품은 코드만 넣고 JS가 몰에서 런타임 fetch→DOM 카드 렌더(153개, 25개+더보기). 실제 몰에서 브랜드·상품명·이미지·가격 파싱 검증 완료.
- §7-9 안전: 엔티티 0 · script 저장 전/후 node --check 통과 · DOM 빌드 방식(속성 이스케이프 문제 회피).
- 구성표 7시트: 카테고리별 코드(OUTER64·TOP23·PANTS57·ACC9=153), 브랜드 16, 섹션 캡처 임베드.
- OUTER/PANTS 순서를 사용자가 기획파일에서 재배치 → 디스크 재읽기(§7-2) 후 fragment·구성표·목업 일괄 반영.
- KV: 사용자 참고이미지(모델+크래프트 테이프) 스타일을 배너 문구(KEEP IT LIGHT·UP TO 70%·09.09-09.15)로 재현. 모델 교체·중간크롭·자켓위주 등 반복 수정 반영.
- 배너 7종: KV와 통일된 모델+테이프 룩.
- 피그마 내보내기: KV·배너를 flat 이미지로, 이어서 **편집 가능한 레이어**(모델 imageHash 재사용, 테이프=오토레이아웃 텍스트, Noto Sans KR/Inter)로 재구성. 모델 크롭은 오버사이즈 사각형+프레임 클립으로 조정.
