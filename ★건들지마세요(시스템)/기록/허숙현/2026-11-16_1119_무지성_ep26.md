## ⚠️ 스타일링 스와이퍼 사진이 잘린다 (게시글 22238 · 원인 확인됨)

실제 게시글을 Node 프록시로 열어 재현했다 (`scratchpad/board_check.mjs`).

- 스타일 게시물 사진 = **750 × 1170** (1 : 1.56)
- PC 스타일링 칸 = **484 × 614** (1 : 1.27) · `object-fit: cover` · `object-position: center center`
- → **위아래로 18.7% 잘린다** (사진 1170 중 219px, 위아래 각 109px). 전신컷이라 **발과 머리끝이 날아간다**

원인은 공통 엔진 CSS `fashionrules26.css` 의 한 줄:
```
191: #sub02_section .styling_area { height: 614px; }       /* 폭은 1fr → 484px */
156: #sub02_section .sub02_content { grid-template-columns: minmax(0,45%) minmax(0,1fr); height: 614px; }
```
614px 은 **옆 상품 영역과 높이를 맞추려고** 잡은 값이고, 폭은 남는 자리를 다 가져가 484가 된다.
같은 사진을 쓰는 다른 자리는 비율을 맞춰 놨다 — 법칙 카드 `aspect-ratio: 1/1.57`, 투표 `2/3`.
**PC 스타일링 칸만 1.27 로 유독 납작하다.**

모바일(463행)은 `aspect-ratio: 2/3` = 1.5 라 3.8% 만 잘려 거의 티가 안 난다.

**이번 변경 때문이 아니다.** `styling_index_nos` 로 바꾸기 전에도 같은 칸·같은 규격이었다.

## 이벤트 투표 첫 사진 바꾸기 (2026-11-16)

**지적**: sub01_list 법칙 썸네일과 이벤트 투표 스와이퍼 첫 장이 같은 사진.

**원인**: 썸네일은 `thumb_image_index: 1` 로 각 법칙 대표 게시물의 1번 사진.
이벤트는 `index_nos` 의 각 게시물에서 `image_index`(=1) 번 사진을 1장씩.
`index_nos[0]` 가 곧 `index_no` 라서 둘이 같은 사진이 된다.
(실제로 재 보니 이벤트 스와이퍼는 법칙별 스타일링 스와이퍼와 **전 장이 동일**했다. 지시대로 첫 장만 손댔다.)

**고침** — 회차 settings 의 개발자 영역만 수정. 공통 엔진은 건드리지 않았다.
`index_nos` 가 2개 이상일 때 `image_indexes` 를 **착장별 순번**(같은 차례)으로 쓰게 했다.
비었거나 모자라면 기존처럼 `image_index`.

```js
return list.map(function(images, order){
    var pick = look.image_indexes[order] || look.image_index;
    return images[pick - 1];
}).filter(Boolean);
```

## 이벤트 투표 사진을 상품 한 벌로 (2026-11-16)

**지적**: 이벤트 스와이퍼에 여러 코디가 섞여 있다. 투표 이미지는 **그 LOOK 상품의 사진만** 들어가야 한다.

LOOK 01 미드나잇 카라 항공점퍼 / 02 BC 셔링 라인 퍼 트림 후드 패딩점퍼 / 03 BC 워시드 유틸 패딩 자켓

**고침**: `rules[].event.index_nos`(착장 섞기)를 빼고, 그 상품 착장 게시물 **한 곳** 안에서 사진 순번을 고른다.

```js
event: {
    image_index: 3,
    image_indexes: [3, 4, 2],   /* 1번은 상단 법칙 썸네일이 쓰고 있으므로 뺀다 */
}
```

- `index_nos` 가 없으면 `index_no` 게시물에서 `image_indexes` 순번 사진들을 쓰는 기존 분기로 돌아간다
- `image_index: 3` — 스크립트가 교체하기 전 공통 엔진이 그리는 1장도 같은 사진이 되게
- 법칙별 스타일링(sub02)은 그대로 여러 착장(`styling_index_nos`)

**검증** (PC·모바일 둘 다 같은 결과)
| LOOK | 썸네일 | 이벤트 스와이프 |
|---|---|---|
| 01 | 22217 #1 | 22217 **#3 #4 #2** |
| 02 | 22236 #1 | 22236 **#3 #4 #2** |
| 03 | 22234 #1 | 22234 **#3 #4 #2** |

전부 한 게시물 안 사진이고 썸네일과 겹치지 않는다.
