## ⚠️ 막힌 점 · 오류

- 시안 CSS 를 `.var_x` 클래스로만 쓰면 원본 `#event_section` id 규칙에 밀림 → 시안은 `#event_section.var_x` 로 격상해야 함
- 로컬 Playwright 에서 `files/board_img_goods/*.jpg` 가 `ERR_NETWORK_ACCESS_DENIED` — 샌드박스 네트워크 제한(curl 은 200·image/jpeg, Referer 무관). 라이브에선 문제 없음. 자동 로드 로직(li 4개·src·href·one 매핑·수동 폴백)은 라우팅 테스트로 확인
- 정리 중 `.tip{height:auto}` 를 '기본값'이라 지웠더니 라이브에서 팁이 사진 위쪽에 뜸 — 몰 공통 CSS `a{height:100%}`(§5-B 단골 3종) 때문. **몰 CSS 되돌리기용 속성은 기본값처럼 보여도 지우지 말 것**. 검증 프리뷰에 `a{height:100%} .cont{text-align:center}` 를 상시 포함하도록 preview_mall.html 추가
- 치환 문자열 실수: '{rate}%' 템플릿에 '10%' 를 넣어 '10%%' — 단위가 템플릿에 있으면 숫자만 넣기
- 같은 실수 2건째: `#pd_section .info_box{display:flex;flex-direction:column}` 도 지웠더니 모바일에서 이름·가격이 가로로 틀어짐 — `info_box` 가 몰 공통 클래스(모바일 `display:flex;align-items:center`). PC `display:block`·모바일 `flex column + align-items:flex-start` 복원. 몰 시뮬 프리뷰에 `.info_box{display:flex;align-items:center}` 추가
- 모바일 사진이 뿌옇게 보이면 해상도보다 먼저 `transform` 애니메이션을 의심 — 사진 감싼 요소엔 translate 쓰지 말고 opacity 만
- 페이드 셀렉터 `#event_section .is_in .x`(자손) 로 써서 섹션 자체의 is_in 을 못 잡음 → `#event_section.is_in .x` 로. 상태 클래스를 어디에 붙이는지와 셀렉터 결합자를 같이 확인할 것
- 쿠폰 타이머: `const iv` 를 tick 정의 뒤에 두면 이미 마감된 상태에서 첫 tick 이 TDZ 오류 → `let iv=null` 먼저 선언
- 정규식 `\d` 를 JS 문자열에 넣으면 도구 경유 시 백슬래시가 깎여 `d` 로 남음 → `[0-9]`·`[.]` 문자클래스로 작성(백슬래시 0개)
- 모달 블록을 문자열 검색으로 잘라 옮길 때 들여쓰기 다른 `</div>` 가 부분 매칭돼 닫는 div 누락 → 섹션이 뒤 섹션을 삼킴. 마크업 이식 후 반드시 `<div`/`</div>` 개수 균형 검사

- 엑셀 첫 파싱(openpyxl) 1.5MB 이미지 포함으로 120s 타임아웃 → read_workbook.py 로 바로 해결
