## ✅ 잘된 점

- **이벤트 4개 + 지도** 구성. EVENT 01 SNS 공유(100만원) / EVENT 02 4XR을 찾아라(커밍순, 검정 풀블리드) / EVENT 03 구매 고객(증정 + 뽑기판) / LOCATION / EVENT 04 댓글 이벤트. 레퍼런스는 KREAM 트렌드 리포트(디자인 시스템만 차용).
- **몰 댓글창을 기획전 안으로 이동** — 가장 까다로웠고 가장 잘 풀린 부분. 복사가 아니라 `.comment_area` 노드를 EVENT 04 안으로 **이동**시켜서, 몰 스크립트(`#memo`·`#board_idx`·`#bbs_tail`)가 손대지 않아도 그대로 동작한다. 등록·목록·정렬탭·페이징·댓글 수 전부 몰 로직 그대로. 로그인 마크업을 몰라도 되는 게 핵심 이점이었다.
  - 모바일 템플릿은 페이징(`.tail_paging`)이 댓글 영역 **밖 형제**라 같이 옮겨야 했다(PC 는 안에 있음).
  - 못 찾으면 아무것도 하지 않고 「댓글 남기러 가기」 버튼이 남는 폴백.
- **PC/모바일 문구를 데이터에서 분리.** 정보줄 `[라벨, 값, 강조, 모바일 라벨, 모바일 값]`, 혜택 모음 `sub` / `sub_m`. 모바일 칸을 비우면 PC 것을 그대로 쓴다. 덕분에 모바일에서 「이벤트 기간 09.01 - 10.05」→「기간 09.01~10.05」로 줄여 참여방법·유의사항을 같은 줄 오른쪽 끝에 맞출 수 있었다(전에는 도구만 둘째 줄로 밀려 있었음).
- **PC 레이아웃 유지 원칙.** 사용자 요청으로, 모바일에서 세로로 쪼갠 좌/우 레이아웃 5곳(D-DAY·정보줄 도구·적립 알림·지도 버튼 3개·댓글 입력+등록)을 PC 방식으로 되돌리고, 폭이 정말 부족한 4곳(혜택 모음·증정/뽑기 카드·EVENT 01 상단·폰 목업)만 쌓아 뒀다.
- **유의사항 노출 방식을 아톰 기획전에 맞춤** — 아래에서 올라오는 시트 → 화면 가운데 레이어, 제목 30px·항목 24px·좌측 정렬.
- 애니메이션: 스크롤 등장(`.rv`/`.rv_f`), 조각 순차 등장(`.rv_seq` + `--i`), 숫자 롤링, 뽑기 IP 아이콘 5종 개별 모션, QR 힌트 말풍선.
- **최종 점검 전부 통과** — 이미지 11개 200 / 외부 링크 정상 / 콘솔 에러 0 / 가로 스크롤 없음 / 모달 6개 정상 / 등장 미실행 0 / 남은 소재 자리 0 / 숨겨둔 빈 요소 0. PC 1440 · 모바일 750 · 몰 PC · 몰 모바일 네 환경에서 확인.

## ⚠️ 막힌 점 · 오류

- **(가장 큰 손실) 몰 모바일 viewport=750 을 몰랐던 것.** 390 기준으로 모바일 크기·레이아웃을 여러 차례 조정했는데 전부 어긋난 기준이었다. 사용자가 "글씨가 작다"고 지적했을 때도 원인을 못 찾고 한 번은 반대로 더 줄였다. 참고 파일(아톰)을 열어보다 우연히 발견했다. **기획전 착수 시 몰 페이지의 viewport 메타부터 확인했어야 했다.**
- **몰 공통 CSS 와의 충돌을 사후에 하나씩 발견.** `a{height:100%}`, `.it_box .btn_up{position:absolute}`, `.cont{text-align:center}` 셋 다 실제 게시글에 올린 뒤에야 드러났다. 로컬 미리보기만으로는 안 잡힌다.
- **내 수정이 만든 부작용 1건** — 앵커 전체 리셋으로 몰 페이징 화살표를 죽였다. 범위를 넓게 잡은 리셋의 대가.
- (환경) figma / higgsfield 재인증 필요 상태. 이 기획전은 피그마 규격 프레임 미생성.
- (환경) D 드라이브 용량 부족으로 작업 폴더를 E 로 이전.

## 💡 개선 요청 (중앙에 전달)

- **스킬 §0 환경 점검에 「몰 페이지 viewport 메타 확인」을 넣어주세요.** `m.4xr.co.kr` 은 `width=750` 입니다. 모바일 크기를 390 기준으로 잡으면 실제 폰에서 절반으로 보입니다. 이번에 가장 크게 헛돈 부분입니다.
- **「몰 공통 CSS 충돌 체크리스트」를 §5-A 에 추가 검토.** 최소한 이 셋은 매번 걸립니다 —
  `a{height:100%}` / `.comment_area .it_box .btn_up{position:absolute; height:200px}` / `.cont{text-align:center}`.
  대응은 `#wrap_ey{text-align:left}` 처럼 **우리 영역 안에서만 되돌리기**. 단, 태그 선택자 전체 리셋(`#wrap_ey a{...}`)은 몰 부품까지 죽이니 금지.
- **댓글창을 기획전 안으로 넣는 패턴을 스킬에 정식 케이스로 넣어주세요.** 복사가 아니라 **노드 이동**이면 몰 스크립트가 그대로 살아납니다. 모바일은 페이징이 밖에 있으니 같이 옮겨야 한다는 점까지. 재사용 가치가 높습니다.
- **PC/모바일 문구 분리**(`sub_m`, 정보줄 모바일 칸)도 스킬에 넣을 만합니다. 모바일에서 문구가 길어 줄이 깨지는 일이 잦습니다.
- 숫자 롤링을 쓸 때 **칸 높이는 1em 이 아니라 1.2em** 으로. 서체에 따라 글자 상자가 1em 을 넘어 잘립니다(SB Aggro 는 1.19em).
