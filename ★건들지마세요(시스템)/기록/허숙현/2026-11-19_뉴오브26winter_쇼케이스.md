## 2026-11-27 · 상단·에디토리얼 사진 교체 (fullpage PSD)

`fullpage/img_fullpage_pc.psd`(1920x11409) 에서 컷을 뽑아 `showcase/img/` 에 넣었다. 이벤트·NEW PRODUCTS 영역은 요청대로 제외.

**뽑은 방법** — PSD 안에 `box`(틀) + `img`(사진) 쌍이 있고 사진이 틀보다 크다. 틀 bbox 로 **합성본(psd.topil())을 잘랐다**. 상단만은 타이틀·라벨 글자가 사진 위에 겹쳐 있어 합성본을 못 쓰고 `top > img` 픽셀 레이어만 붙여서 잘랐다(글자는 HTML 이 그림).

| 자리 | 틀 bbox | 저장 규격 |

| top | 0,71 ~ 1920,974 | 1920x903 |
| wide 5장 (01·05·08·12·15) | y 2172 / 3950 / 5720 / 7506 / 9284, 높이 889 | 1920x889 |
| trio 6장 (02~04·09~11) | 592x762 | **1000x1287 로 확대** (모바일 1단 full width 대비 — 기존 규격 그대로) |

JPEG quality 88 · progressive. 옛 가을 소재 16장은 `showcase/img/_to_delete/26fall_소재/` 로 옮김.

**코드 수정** — `img_editorial15n.jpg` → `img_editorial15.jpg`, 모바일 자르기 위치를 새 사진 기준으로 다시 잡음(와이드 01 `30%`→`25%`, 15 `45%`→`50%`, 모바일 상단 `object-position` `50%`→`35%` — 얼굴이 왼쪽 끝에 붙어서). `crop` 이 없던 와이드(05·08·12)는 원래대로 안 자름.

**검증** — PC 1920 / 모바일 750(isMobile) 렌더: 사진 15장 전부 로드, 블록 구성 wide·trio·wide·pair·wide·trio·wide·pair·wide 유지, 콘솔 오류 0. 58,614 bytes · 엔티티 0 · style 1 · script 1 · @media 1 · 스크립트 문법(원본·언이스케이프) 통과.

**남은 것** — `EDITORIAL` 의 `goods` 는 아직 26FW 가을 상품번호다. 사진은 겨울인데 호버 팁에 가을 상품명이 뜬다. PSD 에도 에디토리얼 상품번호가 없고(04_상품 스마트오브젝트에만 있음), 원본 사진 파일명(`20261026 뉴오브#####.jpg`)에도 없어 자동으로 못 맞춘다 — 사람이 지정해야 함.
