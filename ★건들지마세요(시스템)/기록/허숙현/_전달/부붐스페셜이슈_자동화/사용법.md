## 1. 폴더 만들기

```
python ss.py init "E:\작업\스페셜이슈\<브랜드>\<회차>"
```
만들어지는 것
- `img/top` · `img/pd` · `img/close` — 이미지 넣는 곳
- `fullpage/fullpage.psd` — 레이아웃 PSD. 사진만 바꿔서 이미지를 뽑습니다
- `설정.json` — 이번 회차 내용 (예시로 0918 부붐 값이 들어 있음)
- `_소재/이미지규격.txt`

## 2. 이미지 넣기 (파일명·크기 고정)

| 파일 | 크기 |
|---|---|
| img/top/img_top.jpg | 1922 × 752 |
| img/pd/img_pd01.jpg | 1402 × 822 |

**자동 스와이프**: 아무 칸이든 옆에 `_02` · `_03` … 을 두면 그 칸이 스와이프가 됩니다.
예) `img_pd01.jpg` + `img_pd01_02.jpg` + `img_pd01_03.jpg` → 3장 스와이프

서버(CDN) 경로: `.../tgreen09/<연>/<월>/<일>/<폴더코드>/img/` 에 **같은 폴더 구조로** 올립니다.

## 3. 설정.json 채우기

| 항목 | 예 | 설명 |
|---|---|---|
| 기획전명 | 부붐_26FALL | 붙여넣기 파일 이름에 쓰임 |
| 오픈일 | 2026-09-18 | 서버 이미지 경로 날짜 |
| 폴더코드 | HSH | 서버 이미지 경로 담당자 코드 |
| 브랜드번호 | 137 | BRAND 버튼 → `brand_goods.php?brand=137` |
| 비주얼 | 왼쪽 · 오른쪽(기간) · 제목(줄 목록) | 메인 비주얼 글자 |
| 브랜드소개 | 제목 · 문구(줄 목록) · 배경색 | |
| 엔딩제목 | BOOVOOM | |
| 상품 | 칸별 상품번호 | 스와이프 칸은 `["번호1","번호2",…]` 장 수만큼, 전부 같은 상품이면 번호 하나 |
| 상품명_직접 | {} | 몰 상품명 대신 쓸 이름 (보통 비워 둠) |

- **상품명·가격은 적지 않습니다.** 상품명은 몰에서 자동으로 가져오고, 최종가·할인율은 페이지가 실시간으로 읽습니다.
- **게시글 번호는 어디에도 적지 않습니다.** 어느 글에 붙여도 동작합니다.

## 4. 만들기 → 점검

```
python ss.py make   <회차폴더>     index.html + <기획전명>_비즈호스트_붙여넣기.html
python ss.py check  <회차폴더>     이미지(로컬·서버·크기) · 상품번호 · 코드 규칙
python ss.py render <회차폴더>     PC·모바일 화면 점검 (임시 페이지)
python ss.py render <회차폴더> "<게시글 주소>"   올린 글 기준으로 점검
python ss.py all    <회차폴더> ["<게시글 주소>"]  위 세 개 한 번에
```
화면 캡처는 `_소재/_점검/` 에 저장됩니다.

## 5. 게시판에 올리기

`<기획전명>_비즈호스트_붙여넣기.html` 을 크롬으로 열고 **코드 복사** →
기획전 게시글 수정 → 소스(HTML) 모드 → **기존 본문 모두 지우고** 붙여넣기 → 저장.
(두 번 들어가면 두 번째 블록에 이미지·상품 정보가 안 붙습니다)

## 설치 (다른 PC)
- 필요: Python 3 · Node · Playwright(4XR_기획전 스킬 scripts 폴더의 node_modules — 도구가 위로 올라가며 자동으로 찾음)
- 레이아웃 PSD(57MB)는 저장소에 넣지 않습니다. 없으면 `init` 이 건너뛰고, 이미지 규격표대로 만들면 됩니다

## 고정으로 들어가 있는 기능
- 사진 위 상품 정보: 화면에 들어오면 상품명 · 최종가 · 할인율이 3초 떴다가 사라짐, `+` 로 다시 열기, 누르면 새 창
- 자동 스와이프: 2.2초 간격, 마우스·손가락으로 넘기기, 올려두면 멈춤
- pd_04 콜라주 끌어 옮기기 (PC 마우스 / 모바일 꾹 눌러 끌기)
- 이미지 페이드, 게시판 틀 초기화, 상품 탭 sticky (PC -1px / 모바일 100px)

## 주의
- 레이아웃·효과를 바꾸려면 `template.html` 을 고칩니다 (모든 회차에 적용됨)
- 게시판 스킨에 전역 `a{height:100%}` 가 있어 `.tip{height:auto}` 는 **절대 지우면 안 됨** (지우면 상품 정보가 좌측 상단으로 튐)
- `render` 를 게시글 주소 없이 돌리면 임시 페이지라 가격을 상품 페이지에서 따로 받습니다. 몰이 느리면 가격이 ⚠ 로 표시될 수 있는데 오류가 아닙니다 — 게시글에 올린 뒤 주소를 붙여 다시 점검하면 정확합니다
- 페이지 열기 실패 등이 뜨면 한 번 더 돌려서 판단
