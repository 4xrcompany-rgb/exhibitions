### 실측으로 잡은 몰 환경값 (재현본 상단 `shell` 블록에 기록)

| 항목 | 값 |
|---|---|
| 레이아웃 | PC = 좌우 2단 (`#left` 36% 내부스크롤 / `#right` 상품그리드), 모바일 = 세로 1단 |
| PC 최소폭 | `#wrap{min-width:1600px}` (몰 PC 스킨) — 1440 에서도 1600 으로 가로 스크롤 |
| 모바일 기준 | `viewport width=750` → **CSS px 기준이 750**, `.page_cont.padding_01{padding:0 20px}` → 본문 710 |
| 브레이크포인트 | `@media (max-width:768px)` **하나뿐** (PC/모바일 CSS 동일 파일) |
| 전역 리셋 | `*{margin:0;padding:0;border:0}` · **`body{line-height:1}` (단위없는 1 → 상속)** · content-box |
| letter-spacing | 태그별 **직접지정**(상속 아님). PC `-0.025em` / 모바일 `-0.03em` |
| 폰트 | Pretendard 1.3.8 (jsdelivr). CSS 에 `Bai Jamjuree` 참조 있으나 **로드 링크 없음 → 폴백** |
| 기타 | 몰 PC 스킨에 **`a{height:100%}`** 있음(모바일엔 없음) — 안 넣으면 우측 브랜드링크 높이 어긋남 |

### 삽질에서 배운 것 (다음에 시간 아끼기)

1. `*{line-height:1}` 로 리셋하면 **자식이 부모 line-height 를 못 물려받아** 가격줄 높이가 어긋난다.
   몰은 `body{line-height:1}` 단위없는 값이라 **상속**된다. 반드시 body 에만.
2. letter-spacing 은 반대로 **상속이 아니라 태그별 직접지정**. PC/모바일 값이 다르다.
3. 로컬 파일로 열면 `/shop/view.php` fetch 가 CORS 로 막혀 **상품명·가격이 안 뜬다.**
   → Playwright `route()` 로 CORS 헤더를 붙여 프록시하면 실제 데이터로 대조 가능
   (`scripts/measure_proxy.mjs`). 이거 없으면 "상품 그리드 높이 다름"이 계속 오차로 남는다.
