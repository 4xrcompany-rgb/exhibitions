# 작업기록 (기록/)

여기에 **작업 1건 = 파일 1개**로 기록이 쌓입니다. 중앙(관리자) 옵시디언으로 자동 수집됩니다.

## 규칙 — 충돌이 안 나는 핵심

- 각자 **자기 이름 폴더 안에만** 씁니다.  예) `★건들지마세요(시스템)/기록/황다빈/2026-08-10_0707셀렉샵.md`
- 파일명: `날짜_기획전명.md` (예: `2026-08-10_0707셀렉샵.md`)
- 이름은 각 컴퓨터의 `WHOAMI.txt` 에서 자동으로 읽습니다. 직접 만들 필요 없습니다 —
  클로드가 작업 끝에 템플릿(`templates/작업기록.md`)대로 작성하고 중앙에 올립니다.

## 절대 하지 말 것

- 다른 사람 폴더의 파일을 고치지 마세요. (본인 폴더만)
- `system` 쪽 파일(스킬·규칙)은 관리자만 고칩니다.
