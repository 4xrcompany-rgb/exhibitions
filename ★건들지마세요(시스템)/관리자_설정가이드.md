# 관리자 설정 가이드 — 중앙 옵시디언 + 직원 배포

> 목표: 직원 5~10명이 각자 컴퓨터에서 이 시스템으로 작업하면,
> **작업기록·성공·실패·오류**가 **내(관리자) 옵시디언 한 곳으로 자동 수집**되고,
> 내가 고친 개선분(스킬·규칙)은 **직원들에게 자동 반영**된다.

연결 방식: **GitHub 비공개 저장소**. (사무실에서 시작 → 원격 확장까지 그대로 커버)

```
        ┌──────── GitHub 비공개 저장소 (중앙) ────────┐
        │  .claude/ · CLAUDE.md · 스킬   = system (내가 고침)│
        │  기록/<직원>/…                 = 직원이 씀        │
        │  개선사항/ · 00_대시보드.md    = 내가 봄          │
        └───────┬───────────────────────────┬────────────┘
          pull  │ (개선분 받기)      push    │ (자기 기록 올리기)
        ┌───────┴───────┐             ┌──────┴────────┐
        │ 내 옵시디언(중앙)│  …          │ 직원 컴퓨터 ×N │
        └───────────────┘             └───────────────┘
```

---

## A. 딱 한 번 — GitHub 저장소 만들기 (내가)

1. github.com 로그인 → **New repository**
   - 이름: 예) `4xr-gihoekjeon`
   - **Private** 선택 (반드시)
   - 나머지 비우고 **Create** (README 체크 안 함)
2. 만들어진 저장소 주소를 복사. 예) `https://github.com/내계정/4xr-gihoekjeon.git`
3. 이 폴더를 그 저장소로 올린다. **클로드 코드에서 이렇게 말하면 됩니다:**
   ```
   이 폴더를 github.com/내계정/4xr-gihoekjeon 에 올려줘
   ```
   (내부적으로 `git init → add → commit → remote add → push` 를 대신 해줍니다.
    처음 push 때 브라우저 로그인 창이 한 번 뜨면 로그인하세요.)

> 이미 로컬은 커밋까지 준비돼 있습니다. 원격 주소만 연결해 push 하면 끝입니다.

---

## B. 딱 한 번 — 내 옵시디언(중앙) 설정

1. **옵시디언 설치** → 첫 화면에서 **"Open folder as vault"** →
   방금 올린 이 폴더(`★4XR_기획전_자동화`)를 선택. **이 폴더가 곧 내 볼트입니다.**
   - 대시보드는 `★건들지마세요(시스템)/00_대시보드.md` 에 있습니다. 자주 보니 **별표(즐겨찾기)** 해두세요.
2. 좌하단 톱니(⚙) → **Community plugins** → *Turn on* → **Browse** 에서 설치:
   - **Obsidian Git** — 자동 수집/배포의 핵심
   - **Dataview** — 대시보드 표 자동 집계
   - (선택) **Templater**, **Kanban** — 개선사항 정리용
3. **Obsidian Git 설정** (설정 → Obsidian Git):
   - *Auto pull interval (minutes)*: `10`  ← 직원 기록을 10분마다 받아옴
   - *Pull on startup*: 켜기
   - *Auto push*: 필요시(내가 개선사항/스킬 고쳤을 때 자동 올림) — `10` 권장
4. **Dataview 설정**: *Enable JavaScript Queries* 켜기 (대시보드 일부 계산에 사용)
5. `★건들지마세요(시스템)/00_대시보드.md` 를 열면 실패·오류·직원별 집계가 표로 뜹니다.
   (아직 기록이 없으면 비어 있음 — 직원이 작업하면 채워집니다.
    표가 계속 비어 보이면 Dataview 설치·활성화 여부를 먼저 확인하세요.)

> 나는 주로 **읽습니다.** 직원 기록은 건드리지 않고, 고칠 것은 `개선사항/` 에 정리하고
> 스킬(`.claude/.../SKILL.md`)을 고쳐 push 하면 직원들에게 반영됩니다.

---

## C. 직원마다 한 번 — 배포 (직원 컴퓨터에서)

직원은 git을 몰라도 됩니다. 아래만 한 번 해주면 이후는 자동입니다.

1. **설치**: `사용설명서.html` 의 설치 체크리스트대로 (Node·Python·클로드 코드·Playwright).
   추가로 **Git for Windows** 도 설치(https://git-scm.com) — 로그인 자동 처리기가 같이 깔림.
2. **저장소 받기**: 원하는 위치에서
   ```
   git clone https://github.com/내계정/4xr-gihoekjeon.git
   ```
   (드래그 복사보다 안전 — 숨은 `.claude` 까지 그대로 따라옵니다.)
   - 나는 GitHub에서 그 직원을 **Collaborator 로 초대**해 둡니다
     (저장소 → Settings → Collaborators). 그래야 기록을 push 할 수 있습니다.
3. **이름 지정**: `★건들지마세요(시스템)/WHOAMI.sample.txt` 를 복사해 **저장소 맨 위**에
   **`WHOAMI.txt`** 로 만들고, 안의 이름을 그 직원 이름으로 바꿉니다.
   (이 파일은 동기화 안 됨 = 사람마다 다름. 클로드에게 "내 이름 황다빈으로 WHOAMI 만들어줘" 라고 해도 됩니다.)
4. 끝. 이제 그 폴더에서 클로드 코드를 켜고 평소처럼 작업하면,
   **작업이 끝날 때마다 기록이 자동으로 내 옵시디언에 쌓입니다.**

---

## D. 평소 흐름 (자동)

| 누가 | 무엇을 | 어떻게 |
|---|---|---|
| 직원 | 기획전 작업 | 평소대로 (설명서 순서) |
| 시스템 | 작업 끝 → 기록 작성 + 올리기 | 스킬 §11 이 자동 수행 |
| 나 | 옵시디언에서 확인 | `00_대시보드.md` (10분마다 자동 갱신) |
| 나 | 오류 → 개선 | `개선사항/` 에 정리 → 스킬 수정 → push |
| 직원 | 개선 반영 | 다음 작업 때 자동 pull 로 받음 |

---

## E. 자주 묻는 것

- **충돌 안 나나요?** — 직원은 `기록/<자기이름>/` 에만 씁니다. 서로 다른 파일이라 충돌 없음.
  시스템 파일은 나만 고칩니다.
- **작업물(이미지·엑셀)도 다 올라가나요?** — 아니요. `기획전_제작/` 는 `.gitignore` 로 제외.
  **작은 마크다운 기록만** 올라갑니다(빠르고 가벼움).
- **원격/재택으로 확장되면?** — 그대로 됩니다. GitHub라서 인터넷만 있으면 사무실 밖에서도 동일.
- **개인정보/보안은?** — 반드시 **Private** 저장소. 초대한 직원만 접근.
- **옵시디언 유료 Sync 써야 하나요?** — 아니요. GitHub가 backbone이라 불필요.
