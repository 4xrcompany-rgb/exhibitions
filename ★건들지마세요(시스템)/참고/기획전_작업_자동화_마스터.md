# 【 기획전 작업 자동화 】

쇼핑몰 **기획전 페이지**와 **배너 세트**를 만드는 자급자족 작업 시스템.
규칙·순서·도구·프롬프트·주의사항·진행상태 관리 방식을 모두 담아, **다른 컴퓨터·다른 사람에게 넘겨도 순서·규칙 변경 없이 그대로 작동**한다.
범용본이라 개별 데이터·진행상태는 포함하지 않는다. 각 사용자는 자기 몰·자기 폴더·자기 소재로 처음부터 시작한다.

---

## 0. 시작 전 환경 점검 ★ 무엇보다 먼저

**막힌 환경에서 시작하면 작업 중반에 반드시 멈춘다.**
작업 폴더를 받자마자, 다른 어떤 일보다 먼저 이것부터 한다.

### 0-1. 접근 테스트 (3초)

```bash
for u in \
  "https://<몰 도메인>/" \
  "https://<몰 CDN 도메인>/" \
  "https://mcp.figma.com/" \
  "<이미지 생성 서비스 결과 CDN>"
do
  echo "$(curl -sS -m 10 -o /dev/null -w '%{http_code}' "$u" 2>&1 | tail -1)  <-  $u"
done
```

`000` 또는 `CONNECT tunnel failed` → **차단**

### 0-2. 차단이면 작업을 시작하지 말고 먼저 알린다

> 지금 클라우드에서 실행 중이라 몰 이미지·피그마 업로드가 막혀 있습니다.
> 이대로 진행하면 중간에 손이 여러 번 필요합니다.
> **「컴퓨터에서 실행」으로 다시 시작**하시면 제가 끝까지 처리합니다.

```
데스크톱 앱 → 새 작업 → 오른쪽 위 "Run this task" → "On your computer"
기본값 변경 → 설정 → Cowork → "Run new tasks in the cloud" 끄기
```

### 0-3. 그래도 클라우드에서 진행한다면

**어느 단계에서 사용자 손이 필요한지 처음에 한 번에 다 말한다.**
중간에 하나씩 튀어나오면 사용자가 지친다.

검증된 우회 경로 하나는 반드시 기억한다 — **피그마 업로드는 외부 샌드박스를 경유하면 뚫린다.**

```
Figma MCP upload_assets → submitUrl 받기
  → 인터넷 열린 샌드박스에서 curl 로 이미지 받고 그 submitUrl 로 POST
  → imageHash 로 피그마에서 채우기
```

이 하나로 배너 작업 전체가 풀린다. 사용자가 이미지를 드래그할 필요가 없어진다.

자세한 내용 → `references/env-check.md`

## 0-A. 하는 일 / 안 하는 일

**한다**
- 참고링크(벤치마크 기획전)를 섹션·구좌 단위로 분해
- 작성용 **구성표 엑셀** + **섹션별 소재 폴더** 생성
- 사용자가 채운 구성표를 읽어 **기획전 HTML** 생성
- 몰에서 **상품 이미지·가격·할인율·링크**, **브랜드 로고·영문명·링크** 자동 수집
- **배너 5규격 7장** 생성 (PC 기준 → 사이즈별 재배치)
- 피그마에 **소재 규격 프레임** 생성 (디자이너가 직접 그릴 경우)

**안 한다**
- 사용자가 채워야 할 카피·쿠폰 문구를 임의로 지어내지 않는다 (요청 시에만 초안 제시)
- 구성표 엑셀을 **처음부터 새로 만들어 덮어쓰지 않는다** (§7 위반 항목)
- 몰 관리자 업로드·게시는 하지 않는다 (파일 전달까지)

## 1. 고정 작업 순서

이 순서는 **변경하지 않는다.**

```
⓪  실행 환경 점검  (§0)  ←  무엇보다 먼저
     └ 막혀 있으면 작업 시작 전에 사용자에게 알린다
①  사용자가 작업 폴더를 준다
     └ 폴더 안: 기획 엑셀(참고링크 포함) [+ 선택: 배너 예시 이미지]
②  엑셀을 읽고, 참고링크를 열어 섹션·구좌로 분해
③  _소재 섹션별 폴더 + 구성표 엑셀 생성  →  여기서 멈춘다
④  사용자가 구성표를 채우고 소재를 넣고 저장 (엑셀 닫기)
⑤  "엑셀 반영해줘"  →  읽어서 기획전 HTML 생성
⑥  "배너 만들어줘"  →  배너 7장 생성
```

③ 이후 사용자의 신호(“엑셀 반영해줘”) 없이 ⑤로 넘어가지 않는다.

## 2. 폴더 규격

작업 폴더 아래 `_소재/` 를 만들고 섹션별 하위 폴더를 둔다.
**폴더 개수·이름은 참고링크의 섹션 구성에 따라 달라진다.** 아래는 전형적인 형태.

```
<작업폴더>/
├─ <원본 기획 엑셀>.xlsx          ← 사용자가 준 것
├─ 기획전_구성표.xlsx             ← ③에서 생성
├─ 기획전.html                    ← ⑤에서 생성
└─ _소재/
   ├─ 00_위치안내/               섹션별 화면 캡처 (구좌ID 라벨 표시)
   ├─ 01_KV/                     상단 메인 비주얼
   ├─ 02_혜택/                   쿠폰 영역
   ├─ 03_참여브랜드/              (몰 자동수집이면 비워둠)
   ├─ 04~07_<카테고리별>/         카테고리 상품 섹션
   ├─ 08_중간배너/
   ├─ 09_베스트랭킹/
   ├─ 10_배너/                   ★ 배너 작업물 + 예시 이미지
   └─ 99_공통/
```

각 폴더에 **`_규격안내.txt`** 를 넣는다. 형식:

```
[ 01_KV ] 상단 메인 비주얼 소재

넣을 파일
  kv_bg.jpg        KV 배경 이미지        1920 x 635 px   JPG
  kv_object.png    오브젝트 그래픽        600 x 600 px    PNG (배경 투명)

메모
  - 파일명은 엑셀 [③ 섹션구성] 의 "이미지 파일명" 칸과 같게 맞춰 주세요.
```

자세한 규격 표 → `references/folder-spec.md`

## 3. 구성표 엑셀 구조 (7시트 고정)

`scripts/make_planning_sheet.py` 가 생성한다.

| 시트 | 내용 |
|---|---|
| ① 사용설명 | 채우는 법·색 규칙·주의사항 |
| ② 공통설정 | 기획전명·기간·컬러·폰트·컨텐츠 폭·그리드 칼럼 |
| ③ 섹션구성 | **핵심.** 섹션 그림 → 그 섹션의 구좌 목록 순서로 반복 |
| ④ 상품코드 | 섹션별 사용 Y/N · 노출 개수 · 상품코드 목록 |
| ⑤ 참여브랜드 | 브랜드명 + 몰 자동수집 값(파란 칸) |
| ⑥ 원본참고 | 참고링크·분해 근거 |
| ⑦ 화면 위치 안내 (크게) | 섹션 캡처만 크게 모음 |

### ③ 섹션구성 열 구조 (고정)

```
A:No  B:사용  C:섹션ID  D:섹션명  E:구좌ID  F:구좌명  G:항목
H:유형  I:내용  J:이미지파일명  K:이미지폴더  L:권장규격  M:가이드
```

- **사용(B)** = `Y`/`N`. N이면 그 구좌를 **아예 그리지 않는다**
- **유형(H)** = `텍스트 / 이미지 / 링크 / 색상 / 숫자 / 선택 / 상품코드 / 자동`
- **내용(I)** = 사용자 입력칸 (파란 글씨)
- **자동** 유형은 몰에서 가져오므로 사용자가 채우지 않는다

### 색 규칙 (엑셀)

| 색 | 뜻 |
|---|---|
| 노란 배경 + 파란 글씨 | 사용자가 채우는 칸 |
| **하늘색 배경 + 남색 글씨** | 몰에서 자동 수집된 값. 손대지 않음 |
| 주황 굵은 글씨 | 표기 불일치 경고 (엑셀 표기 ≠ 몰 등록명) |
| 빨간 글씨 | 수집 실패 · 확인 필요 |

### 네비게이션 항목 켜고 끄기

앵커 네비게이션은 **섹션 존재 여부와 별개로** 메뉴에서만 뺄 수 있어야 한다.
③ 섹션구성의 네비 섹션(예: `S02`)에 구좌 `B02 · 네비 항목` 행을 **섹션 수만큼** 만든다.

```
S02  B02  네비 항목  <섹션명> (S03)   선택   Y
S02  B02  네비 항목  <섹션명> (S04)   선택   N   ← 메뉴에서만 빠짐
```

- 항목명 끝의 `(S0x)` 로 섹션과 매칭한다 → 빌더가 정규식 `\((S\d\d)\)` 로 파싱
- `B01 사용 여부 = N` 이면 네비게이션 **전체**가 사라진다

## 4. 몰 데이터 자동 수집

사용자가 준비할 것은 **상품코드와 브랜드명뿐**이다. 나머지는 몰에서 가져온다.

| 대상 | 자동 수집 항목 |
|---|---|
| 상품 | 이미지 · 상품명 · 정가 · 판매가 · 할인율 · 상품 링크 |
| 브랜드 | 로고 이미지 · 영문명 · 브랜드관 링크 · 브랜드관 배너 |

`scripts/fetch_mall.py` 가 수행하며, 셀렉터·URL 패턴은 **`references/config.sample.json`** 에 정의한다.
각 사용자는 자기 몰에 맞게 이 config를 한 번 채운다. (도구 연결은 사용자 준비 사항)

### 브랜드 매칭 규칙 (필수)

```python
def norm(x):  return ''.join(str(x).split())   # 공백 전부 제거
# 엑셀 "브랜드명" 과 몰 등록명을 공백 무시하고 비교
```

- 몰 등록명이 `"히루카 아카이브"`, 엑셀이 `"히루카아카이브"` → **공백 무시 매칭 필수**
- 매칭 후 **몰 등록명 열**을 별도로 채워 보여주고, 표기가 다르면 주황 굵은 글씨로 표시
- 못 찾은 브랜드는 비고 칸에 빨간 글씨로 사유 기록

## 5. 기획전 HTML 생성 규칙

`scripts/build_page.py` 가 수행한다.

### 빈 구좌 처리 — **숨기지 않고 없앤다**

```
사용(B) = N        →  마크업 자체를 만들지 않는다
내용(I) 비어있음    →  마크업 자체를 만들지 않는다
```

빈 껍데기 `<div>`, `display:none`, 플레이스홀더 뱃지를 **남기지 않는다.**
제거한 구좌는 `report.json` 에 목록으로 기록하고 사용자에게 보고한다.

### 연쇄 제거 규칙

| 조건 | 결과 |
|---|---|
| 상품코드 0개 | 그 섹션 **전체** 제거 |
| 필터 칩이 1개뿐 | 칩 줄 전체 제거 (선택지가 없으므로) |
| 버튼 문구는 있고 링크가 없음 | 버튼 제거 |
| 배너 이미지·문구 둘 다 없음 | 배너 섹션 전체 제거 |
| 유의사항 문구 0개 | 유의사항 영역 제거 |

### 이미지 파일 매칭 (느슨한 매칭 필수)

사용자가 `kv_object.png` 를 `kv_object.png.png` 로 저장하는 일이 흔하다.

```python
# 확장자를 반복 제거해 베이스명만 비교, 대소문자 무시
while os.path.splitext(fb)[1] in ('.png','.jpg','.jpeg','.gif','.webp'):
    fb = os.path.splitext(fb)[0]
```

느슨하게 매칭된 건 `MATCHED` 목록에 남겨 사용자에게 알린다.

### 이미지 내장

확인용 HTML은 **처음 보이는 이미지를 base64로 내장**한다 (오프라인·샌드박스에서도 렌더).
- 상품 썸네일: 440×560 로 리사이즈, JPEG q82
- 브랜드 로고: 260×120 로 리사이즈
- 「더보기」로 펼쳐지는 나머지는 몰 CDN URL 그대로

### 5-A. 몰 게시판 적용 ★ 처음부터 이 형태로 만든다

기획전 HTML 은 게시판 본문 안에 들어간다. 위에 **사이트 메뉴바가 있고 그 아래**에 놓인다.
그래서 `<head>` 맨 위에 **고정 블록**을 넣는다. 기획전이 바뀌어도 이 블록은 그대로다.

```html
<link rel="stylesheet" href="<몰 폰트 CSS>">
<style>
/* ═══ 고정 · 기획전이 바뀌어도 그대로 ═══ */
  콘텐츠 틀 초기화 / 관련상품 상단_TAB / 카테고리 / * box-sizing
  @media 1940 이상 / @media 768 이하
/* ═══ 여기까지 고정 ═══ */
</style>
```

**★ 고정 블록만 얹는다. 디자인은 손대지 않는다.**
섹션 구성·색·타이포·문구를 임의로 바꾸거나, 요소를 지우거나, 새로 짜지 않는다.
「깔끔하게 해달라」는 말은 **디자인을 갈아엎으라는 뜻이 아니다.**

**놓치기 쉬운 3가지**

| | |
|---|---|
| 모바일 카테고리 제목은 `.tit_40` 이 아니라 **`.txt_46`** | 두 선택자를 따로 쓴다 |
| 모바일은 로드 직후 섹션이 1개뿐, 나머지는 AJAX | **MutationObserver 로 다시 잡는다** |
| `.img_memo_wrap li{width:25%}` | **탭 개수에 맞춰** 바꾼다 |

### 스크롤 등장 — 이미지·텍스트가 촤르르

기획전에는 **스크롤에 맞춰 요소가 순서대로 올라오는 연출**을 기본으로 넣는다.

```
KV        로드 직후 타이포 → 오브젝트 → 뱃지 → 하단 카피 순으로 상승
섹션 제목  화면에 들어오면 상승 + 페이드
상품 카드  같은 행 안에서 왼쪽부터 55ms 간격으로 순차 (촤르르)
브랜드 로고 45ms 간격
카테고리 제목 이미지  흑백 → 컬러 (.is-saturated)
```

- `.rv` → `.rv.is-in` 전환 + `IntersectionObserver`, 발동한 요소는 `unobserve`
- 지연은 **행 단위로 리셋**한다 (`(i % 열수) * 간격`). 안 그러면 끝쪽 카드가 몇 초씩 늦는다
- 「더보기」로 늦게 들어오는 카드도 `MutationObserver` 로 다시 잡는다
- 끝난 요소는 `will-change` 를 해제한다
- `transform` 으로 위치를 잡아둔 요소(`translate(-50%,-50%)` 등)에
  **등장용 `transform` 을 덮어쓰면 레이아웃이 깨진다.** 그 요소는 별도 키프레임을 쓴다

고정 블록 전문·체크리스트 → **부록 H**

## 7. 주의사항 — 실제로 사고가 났던 항목

이 절은 **전부 실제 사고 기록**이다. 무시하면 같은 사고가 반복된다.

### 7-1. 엑셀 덮어쓰기 사고 ★★★

**증상**: 내가 쓴 내용이 사라지거나, 사용자가 채운 내용이 사라진다.

**원인**: 사용자가 엑셀을 열어둔 채로 내가 파일을 쓰면, 이후 사용자가 저장할 때 **화면에 떠있던 옛 내용이 내 파일을 덮어쓴다.**

**규칙**
1. 구성표 엑셀을 **처음부터 새로 만들어 덮어쓰지 않는다.** 사용자 파일을 읽어 **바뀌는 칸만** 고친다
2. 쓰기 전 **`~$<파일명>.xlsx` 임시 파일 존재 여부로 열림 상태를 확인**한다. 열려 있으면 쓰지 않고 알린다
3. 구조 변경(행 추가 등)이 필요하면 **먼저 사용자에게 알리고** 진행한다
4. 채팅에 올린 파일은 사본이다. **사용자는 폴더 파일만 연다**고 명확히 안내한다

```bash
# 열림 여부 확인
ls -a <작업폴더> | grep '^~\$' || echo "닫혀 있음"
```

### 7-2. 스테일 캐시 사고 ★★★

**증상**: 사용자는 수정했다는데 내가 읽으면 옛날 내용이다. **사용자를 의심하게 된다.**

**원인**: 파일 스테이징 계층이 캐시된 사본을 넘겨준다.

**규칙**: 구성표를 읽을 때는 **반드시 사용자 기기에서 직접 파싱**한다. 스테이징 사본을 믿지 않는다.

```
device_bash 로 xlsx(zip)를 직접 열어 sharedStrings + sheetN.xml 을 파싱
→ 결과를 JSON 으로 기기에 쓰고, 그 JSON(새 파일이라 캐시 없음)만 가져온다
```

구현 → `scripts/read_workbook.py`

읽은 뒤에는 **직전 스냅샷과 diff** 해서 “사용자가 바꾼 것”을 먼저 보고한다.

### 7-3. CSS 퍼센트 패딩 함정

`padding-top: 22%` 는 **부모의 너비** 기준으로 계산된다. 부모가 1870px이면 411px이 된다.
→ 배너처럼 폭이 큰 요소 안에서는 **퍼센트 패딩을 쓰지 않는다.** px 또는 em 으로 고정한다.

만든 뒤에는 반드시 요소 박스를 측정해 검증한다.

```js
document.querySelectorAll('.tri,.sticker').forEach(e => e.getBoundingClientRect())
```

### 7-4. URL 대괄호 미인코딩

몰 CDN 파일명에 `[1]` 같은 대괄호가 섞이는 경우가 있다.
`curl` 은 되는데 **브라우저에서는 이미지가 깨진다.**

```python
from urllib.parse import quote
url = CDN + quote(path, safe='/._-')     # [ ] → %5B %5D
```

### 7-5. 샌드박스에서 외부 이미지 차단

클라우드 컨테이너의 브라우저는 몰 CDN에 못 붙는 경우가 있다 (`ERR_CONNECTION_RESET`).
`curl` 은 프록시를 타서 되지만 브라우저는 안 된다.

→ **검증용 스크린샷을 찍을 때는 이미지를 미리 curl로 받아 base64 내장**한다.
사용자 PC에서는 정상이므로, 이걸 “안 되는 것”으로 보고하지 않는다.

### 7-6. 파일 삭제 불가

사용자 기기 마운트에서는 `rm` 이 막혀 있다.
→ 같은 폴더 아래 **`_to_delete/` 를 만들어 `mv`** 하고, 사용자에게 그 폴더를 지우라고 알린다.

### 7-7. 피그마 seat 한계

피그마 **View seat** 은 에이전트로 편집할 수 없고, MCP 도구 호출 한도도 낮다.
→ 작업 전에 `whoami` 로 seat 을 확인한다. View 면:
- 사용자에게 Full seat 필요를 알리고
- **HTML→JPG 파이프라인으로 우회**한다 (§6)

### 7-8. 사용자 지시 준수

- “규칙 삭제해줘” → 해당 규칙을 즉시 버리고, 무엇을 버렸는지 목록으로 확인시킨다
- “숨기지 말고 없애” → CSS 숨김이 아니라 마크업 제거
- 사용자가 “내 폴더에서 수정했다”고 하면 **의심하기 전에 7-2를 먼저 점검**한다

범용본이라 개별 진행상태는 포함하지 않는다. 각 작업 폴더에서 **파일 존재 여부로 단계를 판정**한다.

| 폴더 상태 | 현재 단계 |
|---|---|

| `기획전.html` 있음 | ⑤ 완료 |
| `_소재/10_배너/*.jpg` 있음 | ⑥ 완료 |

새 폴더를 받으면 **먼저 이 표로 현재 단계를 판정하고 시작한다.**

### 800×464 — 앱 푸시 (3장)

- **★ 아주 간결한 폰트만.** 장식·질감 최소
- 3장은 서로 다른 구성으로:
  - **A** — 타이틀만 + 하단 한 줄
  - **B** — 오브젝트 + 라벨 + 타이틀
  - **C** — 짧은 카피 + 타이틀 세로 스택 + 날짜

- 앱푸시의 텍스트 정렬

# 부록 C — 주의사항 전체


전부 **실제로 사고가 난 항목**이다. 각 항목에 증상 → 원인 → 규칙 순으로 적었다.

---

## 1. 엑셀 덮어쓰기 ★★★

**증상**
- 내가 추가한 행이 사라진다
- 사용자가 채운 내용이 사라진다
- 같은 수정을 여러 번 하게 된다

**원인**
사용자가 엑셀을 열어둔 채로 내가 파일을 쓰면, 이후 사용자가 저장할 때
**화면에 떠있던 옛 내용이 내 파일을 통째로 덮어쓴다.**
반대로 내가 통째로 새로 만들면 사용자 입력이 날아간다.

**규칙**
1. 구성표 엑셀을 **처음부터 새로 만들어 덮어쓰지 않는다.** 사용자 파일을 읽어 **바뀌는 칸만** 고친다
2. 쓰기 전 열림 상태를 확인한다
   ```bash
   ls -a <작업폴더> | grep '^~\$'   # 결과 있으면 열려 있음 → 쓰지 않는다
   ```
3. 구조 변경(행 추가)이 필요하면 **먼저 사용자에게 알린다**
4. 채팅에 올린 파일은 사본이다. **폴더 파일만 연다**고 명확히 안내한다
5. 행을 삽입할 때 이미지가 박힌 시트는 앵커가 어긋난다.
   → 이미지 없는 시트에 넣거나, 시트를 다시 그린다

---

## 2. 스테일 캐시 ★★★

**증상**
사용자는 “수정하고 저장했다”는데 내가 읽으면 옛날 내용이다.
→ **사용자를 의심하고 “수정이 안 들어와 있다”고 잘못 보고하게 된다.**

**원인**
파일 스테이징 계층이 캐시된 사본을 넘겨준다. mtime 은 최신인데 내용은 옛것일 수 있다.

**규칙**
1. 구성표를 읽을 때는 **사용자 기기에서 직접 파싱**한다
   ```
   device_bash → xlsx(zip)를 직접 열어 sharedStrings.xml + sheetN.xml 파싱
              → 결과를 새 JSON 파일로 기기에 저장
              → 그 JSON 만 가져온다 (새 파일이라 캐시 없음)
   ```
2. 읽은 뒤 **직전 스냅샷과 diff** 해서 “사용자가 바꾼 것”을 먼저 보고한다
3. 사용자가 “내 폴더에서 수정했다”고 하면 **의심하기 전에 이 항목을 먼저 점검**한다
4. 파싱용 임시 JSON은 작업 후 `_to_delete/` 로 치운다

---

## 3. CSS 퍼센트 패딩

`padding-top: 22%` 는 **부모의 너비** 기준이다.
부모가 1870px이면 411px이 되어 요소가 프레임 전체를 덮는다.

→ 폭이 큰 컨테이너 안에서는 **퍼센트 패딩을 쓰지 않는다.** px 또는 em.
→ 만든 뒤 `getBoundingClientRect()` 로 반드시 검증한다.

---

## 4. URL 대괄호 미인코딩

CDN 파일명에 `[1]` 같은 대괄호가 섞이면 **브라우저에서만 이미지가 깨진다.**
`curl` 은 되기 때문에 원인을 찾기 어렵다.

```python
from urllib.parse import quote
url = CDN + quote(path, safe='/._-')     # [ ] → %5B %5D
```

---

## 5. 샌드박스 외부 이미지 차단

클라우드 컨테이너의 브라우저는 외부 CDN에 못 붙는 경우가 있다 (`ERR_CONNECTION_RESET`).
`curl` 은 프록시를 타서 되지만 브라우저는 안 된다.

→ 검증용 스크린샷을 찍을 때는 **이미지를 미리 curl로 받아 base64 내장**한다.
→ 사용자 PC에서는 정상이므로 이것을 “안 되는 것”으로 보고하지 않는다.

---

## 6. 웹폰트 CDN 스텁

`cdn.jsdelivr.net` 에서 woff2 를 직접 받으면 **100바이트짜리 리다이렉트 스텁**이 받아지는 경우가 있다.

```bash
npm pack pretendard && tar xzf pretendard-*.tgz
ls package/dist/web/static/woff2/
```
받은 파일 크기를 확인한다. 정상이면 700KB 이상.

---

## 7. 파일 삭제 불가

사용자 기기 마운트에서 `rm` / `rmdir` / `unlink` 는 막혀 있다.

→ 같은 폴더 아래 **`_to_delete/` 를 만들어 `mv`** 한다
→ 사용자에게 “그 폴더를 직접 지워주세요”라고 알린다

---

## 8. 피그마 seat 한계

**View seat** 은
- 에이전트로 디자인을 편집할 수 없다 (읽기 전용 대화만)
- MCP 도구 호출 한도가 낮아 몇 번 만에 막힌다

→ 작업 전 `whoami` 로 seat 확인
→ View 면 사용자에게 Full seat 필요를 알리고 **HTML→JPG 파이프라인으로 우회**

---

## 9. 폴더 접근 권한

작업 폴더 밖의 참고 자료는 접근 권한이 없다.
→ 경로를 확인한 뒤 **필요한 최소 폴더만 한 번에** 요청한다. 여러 번 나눠 묻지 않는다.

---

## 10. 사용자 지시 준수

| 사용자 말 | 해야 할 것 |

| “규칙 삭제해줘” | 즉시 버리고, **무엇을 버렸는지 목록으로** 확인시킨다 |

| “예시 넣을게” | 그 예시를 **기준으로 삼는다.** 임의로 스타일을 정하지 않는다 |

# 부록 E — scripts/read_workbook.py

```python
# -*- coding: utf-8 -*-
"""
구성표 엑셀 직접 파서 — 스테일 캐시 회피용.

사용자 기기에서 실행한다 (device_bash). xlsx 는 zip 이므로 표준 라이브러리만으로
sharedStrings.xml + sheetN.xml 을 직접 읽는다. openpyxl 불필요.

  python3 read_workbook.py <xlsx경로> [출력json경로]

출력 JSON:
  { "sheets": { "<시트명>": [ {"A":"값","B":"값",...}, ... ] } }

빌더는 이 JSON 만 읽는다. 스테이징 사본을 믿지 않는다.
"""
import sys, os, re, json, zipfile
import html as H


def parse(xlsx_path):
    z = zipfile.ZipFile(xlsx_path)

    # 공유 문자열
    ss = []
    if 'xl/sharedStrings.xml' in z.namelist():
        raw = z.read('xl/sharedStrings.xml').decode('utf-8', 'ignore')
        for si in re.findall(r'<si>(.*?)</si>', raw, re.S):
            ss.append(H.unescape(''.join(re.findall(r'<t[^>]*>(.*?)</t>', si, re.S))))

    # 시트명 → 파일 매핑
    wb = z.read('xl/workbook.xml').decode('utf-8', 'ignore')
    names = re.findall(r'<sheet[^>]*name="([^"]+)"[^>]*r:id="rId(\d+)"', wb)

    out = {}
    for name, rid in names:
        cand = f'xl/worksheets/sheet{rid}.xml'
        if cand not in z.namelist():
            continue
        sh = z.read(cand).decode('utf-8', 'ignore')
        rows = []
        for rn, body in re.findall(r'<row r="(\d+)"[^>]*>(.*?)</row>', sh, re.S):
            cells = {}
            pat = r'<c r="([A-Z]+)\d+"([^>]*)>(?:<v>(.*?)</v>)?(?:<is><t[^>]*>(.*?)</t></is>)?'
            for m in re.finditer(pat, body):
                col, attr, v, inline = m.group(1), m.group(2), m.group(3), m.group(4)
                if inline is not None:
                    cells[col] = H.unescape(inline)
                elif v is None:
                    cells[col] = ''
                elif 't="s"' in attr:
                    i = int(v)
                    cells[col] = ss[i] if i < len(ss) else ''
                else:
                    cells[col] = v
            if cells:
                cells['_row'] = rn
                rows.append(cells)
        out[H.unescape(name)] = rows
    return out


def main():
    if len(sys.argv) < 2:
        print(__doc__)
        sys.exit(1)
    src = sys.argv[1]
    dst = sys.argv[2] if len(sys.argv) > 2 else os.path.join(os.path.dirname(src) or '.', '_parsed.json')
```

```python
# -*- coding: utf-8 -*-
"""
몰 상품·브랜드 데이터 수집.

  python3 fetch_mall.py config.json [상품코드파일.txt] [브랜드명파일.txt]

출력: mall_data.json
  { "products": { "<코드>": {"n":상품명,"amt":정가,"damt":판매가,"img":이미지URL} },
    "brands":   { "<브랜드명>": {"id":..,"logo":..,"banner":..,"eng":..,"title":몰등록명} } }

셀렉터·URL 패턴은 config.json 의 mall 블록에서 읽는다.
각 사용자는 자기 몰에 맞게 config 를 한 번만 맞추면 된다.
"""
import sys, os, re, json, urllib.request, urllib.parse
import concurrent.futures as cf

CFG = json.load(open(sys.argv[1] if len(sys.argv) > 1 else 'config.json', encoding='utf-8'))
M = CFG['mall']
SEL = M['selectors']
UA = M.get('user_agent', 'Mozilla/5.0')


def get(url, timeout=25):
    req = urllib.request.Request(url, headers={'User-Agent': UA})
    return urllib.request.urlopen(req, timeout=timeout).read().decode('utf-8', 'ignore')


def norm(x):
    """공백 전부 제거 — 브랜드명 매칭용. 몰 등록명과 엑셀 표기의 띄어쓰기 차이를 흡수."""
    return ''.join(str(x).split())


def enc(path):
    """CDN 경로에 [ ] 같은 문자가 있으면 브라우저에서 깨진다. 반드시 인코딩."""
    return urllib.parse.quote(str(path), safe='/._-')


# ---------------------------------------------------------------- 브랜드
def brand_index():
    """브랜드 목록 페이지에서 {brandId: 표시명} 을 만든다."""
    try:
        t = get(M['brand_list_url'])
    except Exception as e:
        print('brand_list 실패:', e)
        return {}
    idx = {}
    for bid, inner in re.findall(SEL['brand_link_in_list'], t, re.S):
        txt = re.sub(r'<[^>]+>', ' ', inner)
        txt = re.sub(r'\s+', ' ', txt).strip()
        if txt:
            idx.setdefault(bid, txt)
    return idx


def find_brand_id(name, idx):
    key = norm(name)
    for bid, disp in idx.items():
        if key and key in norm(disp):
            return bid
    return None


def fetch_brand(args):
    name, bid = args
    if not bid:
        return name, {'id': None, 'logo': None, 'banner': None, 'eng': '', 'title': ''}
    try:
        t = get(M['brand_page_url'].format(id=bid))
        g = lambda k: (re.search(SEL[k], t).group(1).strip() if re.search(SEL[k], t) else '')
        return name, {
            'id': bid,
            'logo': g('brand_logo') or None,
            'banner': g('brand_banner') or None,
            'eng': g('brand_title_en'),
            'title': g('brand_title'),
        }
    except Exception as e:
        return name, {'id': bid, 'logo': None, 'banner': None, 'eng': '', 'title': '',
                      'error': str(e)[:60]}


# ---------------------------------------------------------------- 상품
def fetch_product(code):
    """상품 상세에서 이름·가격·이미지를 뽑는다.
    몰마다 마크업이 다르므로 og 태그를 1차, 정규식을 2차로 쓴다."""
    try:
        t = get(M['product_view_url'].format(code=code))
    except Exception:
        return code, None
    def og(prop):
        m = re.search(rf'property=["\']og:{prop}["\'][^>]*content=["\']([^"\']+)', t)
        return m.group(1).strip() if m else ''
    name = og('title')
    img = og('image')
    nums = re.findall(r'([0-9]{1,3}(?:,[0-9]{3})+)\s*원', t)
    amt = nums[0] if nums else ''
    damt = nums[1] if len(nums) > 1 else ''
    if not (name or img):
        return code, None
    return code, {'n': name, 'amt': amt, 'damt': damt, 'img': img}


# ---------------------------------------------------------------- main
def main():
    codes, names = [], []
    if len(sys.argv) > 2 and os.path.exists(sys.argv[2]):
        codes = [l.strip() for l in open(sys.argv[2], encoding='utf-8') if l.strip()]
    if len(sys.argv) > 3 and os.path.exists(sys.argv[3]):
        names = [l.strip() for l in open(sys.argv[3], encoding='utf-8') if l.strip()]

    out = {'products': {}, 'brands': {}}

    if names:
        idx = brand_index()
        pairs = [(n, find_brand_id(n, idx)) for n in names]
        with cf.ThreadPoolExecutor(10) as ex:
            for n, d in ex.map(fetch_brand, pairs):
                if d.get('logo'):
                    d['logo_url'] = M['cdn_brand'].rstrip('/') + '/' + enc(
                        d['logo'].replace(M['cdn_brand'], ''))
                out['brands'][n] = d
        ok = sum(1 for d in out['brands'].values() if d.get('logo'))
        print(f'브랜드 로고 {ok}/{len(names)}')
        for n, d in out['brands'].items():
            if not d.get('logo'):
                print('  못 찾음:', n, '← 몰 등록명을 확인하세요 (띄어쓰기는 무시하고 찾습니다)')
            elif d.get('title') and norm(d['title']) != norm(n):
                print('  표기 다름:', n, '→', d['title'])

    if codes:
        with cf.ThreadPoolExecutor(12) as ex:
            for c, d in ex.map(fetch_product, codes):
                if d:
                    out['products'][c] = d
        print(f'상품 {len(out["products"])}/{len(codes)}')

    json.dump(out, open('mall_data.json', 'w', encoding='utf-8'), ensure_ascii=False)
    print('-> mall_data.json')


if __name__ == '__main__':
    main()
```

```javascript
// 배너 HTML → 정확한 픽셀 크기의 JPG 캡처
//
```

# 부록 G — 실행 환경 점검 상세


이 문서는 SKILL.md §0 의 상세판이다.
**막힌 환경에서 시작하면 작업 중반에 반드시 멈춘다.** 그래서 무엇보다 먼저 한다.

---

## 1. 왜 이게 첫 단계인가 — 실제 사고 기록

한 번의 기획전 작업에서 아래가 전부 중반에 터졌다.

| 터진 지점 | 증상 | 그때 손실 |
|---|---|---|
| 힉스필드 → 작업공간 이미지 다운로드 | `403 CONNECT tunnel failed` | 생성한 이미지를 볼 수도, 전달할 수도 없음 |
| 작업공간 → 피그마 이미지 업로드 | `403` | 배너를 못 만듦. 사용자에게 드래그를 시킴 |
| 몰 CDN 상품 이미지 | `403` | 상품 사진을 못 씀 |
| 몰 사이트 HTML | `403` | 하우스 스타일 참고 불가 |
| 완성본 JPG → 사용자 폴더 | 불가 | 사용자가 직접 Export |

전부 **시작 전 3초짜리 점검**으로 알 수 있었던 것들이다.
알았다면 처음부터 사용자 컴퓨터에서 실행해 한 번에 끝났다.

---

## 2. 점검 스크립트

작업 폴더를 받자마자, 다른 어떤 일보다 먼저 실행한다.

```bash
# config.json 의 mall.base / mall.cdn_goods 와
# 사용할 도구의 도메인을 넣는다
for u in \
  "https://<몰 도메인>/" \
  "https://<몰 CDN 도메인>/" \
  "https://mcp.figma.com/" \
  "https://www.figma.com/" \
  "<이미지 생성 서비스 결과 CDN>"
do
  code=$(curl -sS -m 10 -o /dev/null -w '%{http_code}' "$u" 2>&1 | tail -1)
  echo "$code  <-  $u"
done
```

**판정**

| 코드 | 뜻 |
|---|---|
| `200` `301` `302` `403`(서버가 준 것) | 통과 |
| `000` | **차단.** 프록시가 CONNECT 를 거부 |
| `403 CONNECT tunnel failed` | **차단** |

`curl` 이 `(56) CONNECT tunnel failed, response 403` 을 뱉으면 허용 목록 밖이다.

---

## 3. 차단이면 — 시작 전에 알린다

작업을 시작하지 말고 먼저 이렇게 말한다.

> 지금 클라우드에서 실행 중이라 아래가 막혀 있습니다.
> · 몰 상품 이미지 (`<도메인>`)
> · 피그마 이미지 업로드 (`mcp.figma.com`)
> · 생성 이미지 다운로드 (`<CDN>`)
>
> 이 상태로 진행하면 중간에 티그린님 손이 여러 번 필요합니다.
> **데스크톱 앱에서 이 작업을 「컴퓨터에서 실행」으로 다시 시작하시면**
> 제가 처음부터 끝까지 처리할 수 있습니다.

**여는 법 두 가지**

```
새 작업 시작할 때
  데스크톱 앱 → 오른쪽 위 "Run this task" → "On your computer"

기본값으로 바꾸기
  설정 → Cowork → "Run new tasks in the cloud" 끄기
```

메뉴가 안 보이면 그 계정에서 아직 지원되지 않는 것이다.

**조직 설정으로 여는 방법** (Team / Enterprise 플랜만)

```
조직 설정 → Capabilities → Code execution → 네트워크 egress
  → "추가 허용 도메인" 에 필요한 도메인 추가
```

- 새 세션부터 적용된다. 진행 중인 대화에는 반영 안 됨
- 이 기능은 버그 신고가 여러 건 있다. 넣어도 안 먹을 수 있음
- Pro·개인 계정에는 이 설정이 없다

## 4. 그래도 클라우드에서 해야 한다면 — 검증된 우회 경로

실제로 통했던 방법만 적는다.

### 4-1. 피그마에 이미지 넣기 ★ 핵심

작업공간에서 `mcp.figma.com` 이 막혀도, **인터넷이 열린 외부 샌드박스를 경유**하면 된다.

```
① Figma MCP  upload_assets  호출  →  submitUrl 받음
② 인터넷 열린 샌드박스에서:
     curl -sL -o img.png "<이미지 원본 URL>"
     curl -X POST -F "file=@img.png;type=image/png" "<submitUrl>"
③ 응답의 imageHash 를 받아 use_figma 에서 채우기로 사용
```

이 한 가지로 배너 작업 전체가 풀린다. **사용자가 드래그할 필요가 없어진다.**

### 4-2. 생성한 이미지를 내 눈으로 확인하기

CDN 이 막혀 다운로드가 안 되면, **피그마에 올린 뒤 `get_screenshot` 으로 본다.**

```
샌드박스에서 이미지 → 피그마 업로드 → 노드를 원본 비율로 resize
  → get_screenshot  →  화면에서 확인
```

여러 장을 한 번에 보려면 샌드박스에서 **컨택트 시트**로 합쳐 한 장만 올린다.

### 4-3. 몰 상품 이미지 쓰기

작업공간에서 몰 CDN 이 막혀도 샌드박스에서는 열리는 경우가 있다.

```
기획전 HTML 에서 상품 이미지 URL 추출
  → 샌드박스에서 curl 로 받기
  → 크롭·리사이즈
  → 4-1 방식으로 피그마 업로드
```

### 4-4. 완성본을 사용자 폴더에 저장하기

**클라우드에서는 불가능하다.** 렌더된 파일을 작업공간으로 가져올 길이 없다.

| 상황 | 방법 |
|---|---|
| 단색 + 텍스트만 있는 프레임 | 피그마에서 좌표·색·문구를 읽어 **HTML 로 똑같이 재현** → Playwright 캡처 → 폴더 저장 |
| 사진·AI 이미지가 들어간 프레임 | **사용자가 피그마에서 Export** (7개 선택 → JPG 1x) |

base64 로 잘라 넘기는 방법은 쓰지 않는다. 배너 한 장이 base64 10만 자를 넘어 현실적이지 않다.

# 부록 H — 기획전 HTML 고정 블록


기획전 HTML 은 **몰 게시판 본문 안**에 들어간다. 위에 사이트 메뉴바가 있고 그 아래에 놓인다.
그래서 `<head>` 맨 위에 아래 **고정 블록**을 넣는다. 기획전이 바뀌어도 이 블록은 그대로다.

**★ 고정 블록만 얹는다. 디자인은 손대지 않는다.**
섹션 구성·색·타이포·문구를 임의로 바꾸거나, 요소를 지우거나, 새로 짜지 않는다.

게시판이 「관련상품」 기능으로 만드는 영역도 있다. 그쪽은 마크업을 우리가 만들지 않고
**CSS 만 씌운다.**

```
section.magazine_view
 ├ div.cont              ← 우리 기획전 HTML
 ├ ul.img_memo_wrap      ← 상단 탭. 게시판이 만든다
 └ section.discount_view × N   ← 카테고리 + 상품. 게시판이 만든다
```

## 파일 구조

```html
<link rel="stylesheet" href="<몰 폰트 CSS>">
<style>

  /* ═══ 기획전마다 교체 ═══ */

<section class="content_box"> … 소개 … </section>
```

## 스크롤 등장 — 이미지·텍스트가 촤르르

기획전에는 스크롤에 맞춰 요소가 순서대로 올라오는 연출을 기본으로 넣는다.

```css
.rv{opacity:0;transform:translateY(32px);
    transition:opacity .6s ease,transform .6s cubic-bezier(.2,.75,.25,1);
    will-change:transform,opacity}
.rv.is-in{opacity:1;transform:none}
.rv.is-done{will-change:auto}
```

```js
const io=new IntersectionObserver((es,ob)=>{es.forEach(e=>{
  if(!e.isIntersecting)return;
  e.target.classList.add('is-in'); ob.unobserve(e.target);
  setTimeout(()=>e.target.classList.add('is-done'),1400);
});},{threshold:.12,rootMargin:'0px 0px -8% 0px'});

// 지연은 행 단위로 리셋한다
el.style.transitionDelay = ((i % 열수) * 55) + 'ms';
```

| 대상 | 연출 |
|---|---|
| KV | 로드 직후 타이포 → 오브젝트 → 뱃지 → 하단 카피 순 상승 |
| 섹션 제목 | 화면 진입 시 상승 + 페이드 |
| 상품 카드 | 같은 행 안에서 왼쪽부터 **55ms** 간격 |
| 브랜드 로고 | **45ms** 간격 |
| 카테고리 제목 이미지 | 흑백 → 컬러 (`.is-saturated`) |

**주의**

- 지연을 인덱스 전체에 곱하면 마지막 카드가 **수십 초 뒤에** 나온다. 반드시 행 단위로 리셋
- 「더보기」로 늦게 들어오는 카드는 `MutationObserver` 로 다시 잡는다
- 발동한 요소는 `unobserve`, 끝난 요소는 `will-change` 해제
- ★ `transform:translate(-50%,-50%)` 로 **위치를 잡아둔 요소**에 등장용 `transform:translateY()`
  를 덮어쓰면 **가운데 정렬이 깨진다.** 그 요소는 `translate(-50%,calc(-50% + 46px))` →
  `translate(-50%,-50%)` 로 가는 **별도 키프레임**을 쓴다
