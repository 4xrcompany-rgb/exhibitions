# 개선사항 (개선사항/)

관리자(중앙)가 직원들의 `기록/`에서 올라온 오류·개선요청을 보고,
**고칠 것**을 여기로 옮겨 정리하는 공간입니다.

## 흐름

```
기록/<직원>/…  (오류·개선요청 발생)
      │  관리자가 대시보드에서 확인
      ▼
개선사항/     (여기에 이슈로 정리)
      │  관리자가 스킬·규칙 수정 (system 쪽)
      ▼
git push → 직원들 다음 작업 때 자동 반영(pull)
```

## 파일 예시

`개선사항/2026-08_배너폰트404.md` 처럼 이슈 하나당 파일 하나.
프론트매터에 `상태: 열림 / 진행 / 완료` 를 두면 대시보드에서 집계됩니다.
