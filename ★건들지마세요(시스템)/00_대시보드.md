# 📊 4XR 기획전 작업 대시보드

> 이 표들은 **Dataview** 플러그인이 있어야 자동으로 채워집니다. (관리자 옵시디언에 설치)
> `기록/` 에 쌓인 작업기록을 실시간 집계합니다.

> 🗺 그래프로 보기 → [[맵]] (작업자·기획전별로 뭉친 별자리)

## 🔵 지금 진행 중 (아직 안 끝난 작업 — 30분마다 갱신)

```dataview
TABLE 작업자, 기획전, 날짜, file.mtime AS 최근갱신
FROM "★건들지마세요(시스템)/기록"
WHERE 상태 = "진행중"
SORT file.mtime DESC
```

## ⚠️ 손봐야 할 것 — 실패 · 부분성공

```dataview
TABLE 작업자, 기획전, 날짜, 상태
FROM "★건들지마세요(시스템)/기록"
WHERE 상태 = "실패" OR 상태 = "부분성공"
SORT 날짜 DESC
```

## 🧯 오류 모아보기

```dataview
TABLE WITHOUT ID 작업자, 기획전, 날짜, 오류
FROM "★건들지마세요(시스템)/기록"
WHERE 오류
SORT 날짜 DESC
```

## 👥 직원별 작업 건수

```dataview
TABLE rows.length AS 건수,
      length(filter(rows.상태, (s) => s = "진행중")) AS 진행중,
      length(filter(rows.상태, (s) => s = "성공")) AS 성공,
      length(filter(rows.상태, (s) => s = "실패")) AS 실패
FROM "★건들지마세요(시스템)/기록"
WHERE 작업자
GROUP BY 작업자
```

## 🕒 최근 작업 30건

```dataview
TABLE 작업자, 기획전, 상태, 소요
FROM "★건들지마세요(시스템)/기록"
SORT 날짜 DESC
LIMIT 30
```

## 🛠 개선사항 진행

```dataview
TABLE 상태, file.mtime AS 수정일
FROM "★건들지마세요(시스템)/개선사항"
```
