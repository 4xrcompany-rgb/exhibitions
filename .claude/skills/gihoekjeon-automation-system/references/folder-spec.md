# 소재 폴더 규격

`_소재/` 아래 섹션별 폴더를 만들고, 각 폴더에 `_규격안내.txt` 를 넣는다.
**폴더 구성은 참고링크의 섹션 구조에 따라 달라진다.** 아래는 전형적인 기본형.

---

## `_규격안내.txt` 템플릿

```
[ <폴더명> ] <용도 한 줄>

넣을 파일
  <파일명>    <설명>    <가로> x <세로> px    <형식>

메모
  - <이 소재가 화면 어디에 들어가는지>
  - <안 넣으면 어떻게 되는지>
  - 파일명은 엑셀 [③ 섹션구성] 의 "이미지 파일명" 칸과 같게 맞춰 주세요.
```

### 자동 수집 폴더는 이렇게 쓴다

```
[ 03_참여브랜드 ] 브랜드 로고

★ 이 폴더는 비워 두셔도 됩니다.

브랜드 로고는 몰에 등록된 이미지를 브랜드ID로 자동으로 가져옵니다.

  자동으로 따라오는 것
    - 브랜드 로고 이미지 / 영문명 / 브랜드관 링크 / 브랜드관 배너

  직접 넣어야 하는 경우
    - 몰 로고 대신 다른 로고를 쓰고 싶을 때
    - 몰에서 못 찾은 브랜드
    → {브랜드명}.png (200 x 200, 배경 투명) 으로 넣어 주세요.
       같은 이름의 파일이 있으면 몰 로고 대신 그 파일을 씁니다.
```

---

## 파일명 규칙

- 엑셀 ③ 섹션구성의 **「이미지 파일명」 칸과 동일**하게 저장
- 빌더는 **확장자 중복·대소문자를 무시**하고 매칭한다
  (`kv_object.png.png` → `kv_object.png` 로 인식하고 사용자에게 알림)
- `_` 로 시작하는 파일은 소재로 취급하지 않는다 (`_규격안내.txt` 등)

---

## 위치안내 캡처 만드는 법

참고링크 페이지를 섹션 단위로 캡처하고, **각 구좌에 분홍 라벨**로 구좌ID·항목명을 얹는다.
이 캡처를 ③ 섹션구성 시트의 각 섹션 블록 위와 ⑦ 시트에 넣는다.
사용자가 “이 칸이 화면 어디인지” 묻지 않게 하는 것이 목적이다.
