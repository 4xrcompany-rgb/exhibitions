# 대형 기획전 자동화 (추석 기획전 타입)

Claude 에게 **"대형 기획전 타입 시작해줘"** 라고 하면 아래 순서로 진행해요.
쿠폰 · 상품권 · 럭키백 · 데일리 특가 2개 · 후기 이벤트 · 로또 · 실시간 랭킹 · 회원 혜택이 들어가는 큰 기획전이에요.

## 구조

| 무엇 | 어디 | 기획전마다 바뀌나 |
|---|---|---|
| 모양 · 기능 (공통 파일) | `engine/big_event.css` · `engine/big_event.js` → CDN `…/2026/00/bigevent/css/` · `/js/` | 아니요 (처음 한 번, 고칠 때만 올림) |
| 기획전 내용 (설정 파일) | `settings_bigevent.js` → CDN `…/연/월/일/폴더코드/` | 예 |
| 이미지 | `img/…` → CDN `…/연/월/일/폴더코드/img/` | 예 |
| 게시판 붙여넣기 | `index.html` (화면 틀 + 불러오는 줄) | 예 |

CDN 앞부분 : `https://cdn-tgreen.bizhost.kr/phpskr/tgreen09/`

## 명령

| 순서 | 명령 | 하는 일 |
|---|---|---|
| ① | `python be.py init <기획전폴더> --open 2026-10-01 --code HSH` | 폴더 뼈대 · `img/` 폴더들 · `이미지_목록.md` · `대형기획전.json`(오픈일·폴더코드) |
| ② | `python be.py make <기획전폴더>` | 기획 엑셀 → `settings_bigevent.js` + `index.html`. 이미 있으면 `_자동생성/` 에 만든다(덮지 않음) |
| ③ | `python be.py check <기획전폴더>` | 상품번호가 살아 있는지 · 데일리 날짜가 기간 안인지 · 하루 12개인지 · 이미지가 있는지 |
| ④ | `python be.py render <기획전폴더> [게시글주소]` | 실제 기획전 글에 끼워 PC 1920 · 모바일 750 화면 검사 → `_점검/render_pc.png` · `render_mo.png` |
| | `python be.py all <기획전폴더>` | ③ + ④ |

## 기획 엑셀 (에디터가 주는 '기획파일' 시트 그대로)

C열 항목 이름으로 섹션을 찾아요. 칸 위치가 조금 달라도 이름만 맞으면 읽어요.

| C열 항목 이름에 이 말이 있으면 | 읽는 것 |
|---|---|
| 메인 타이틀 | G칸 첫 줄 = 제목, `(○○ 기획전)` = 기획전 이름 |
| 서브 타이틀 | T칸 `2026.09.14 - 2026.09.27` = 기간, `up to 76%` |
| 쿠폰 | X칸 `10% 쿠폰` + Y칸 `…rcoupen.php?idx=868` = 쿠폰 · T칸 `-` 줄 = 유의사항 · G칸 = 문구 |
| 예치금 · 상품권 | X칸 상품번호 + Y칸 `[… 상품권] 30만원권 (5%할인)` · T칸 유의사항 |
| 럭키백 | X칸 상품번호 · Y칸 이름 · T칸 `59,500원에 판매` |
| H칸이 `날짜` 인 항목 (순서대로 2개) | 데일리 특가 1 · 2 — `날짜 · 상품번호 · 브랜드` 세 칸씩 |
| 후기 | G칸 `기존 1,000원 → 10,000원` · T칸 유의사항 |
| 로또 | G칸 `예치금 100만원` · T칸 유의사항 |
| 가족 · 가입 · 회원 | 회원 혜택 섹션 (내용은 4XR 공통 혜택 그대로) |

- **엑셀에 없는 섹션은 통째로 빠져요**(스티키 탭 · 퀵 메뉴 칸도 같이). 빈 칸을 숨기지 않고 아예 안 만들어요.
- 엑셀에 없는 값(비주얼 제목 위치 · 퀵 메뉴 짧은 이름 · 로또 소개 글 · 회원 혜택)은 추석 값으로 두고 `make` 가 **'확인 필요'** 로 알려 줘요.
- 추석 페이지에만 있던 유의사항 줄(고객센터 번호 등)은 엑셀에 없으면 빠지고, 그 줄이 무엇인지 알려 줘요.

## 이미지

`이미지_목록.md` 에 있는 이름·크기 그대로 `img/` 아래에 넣어요(추석과 같은 이름이면 그대로 들어가요).
섹션 제목 이미지(`img/pd/title/tt_*.png`)가 없으면 글자 제목으로 나와요. `render` 는 올리기 전에도 `img/` 의 파일로 보여 줘요.

## 올리는 순서

1. (처음 한 번 · 공통 파일을 고쳤을 때만) `engine/big_event.css` · `big_event.js` 를 CDN `2026/00/bigevent/css/` · `/js/` 에
2. `settings_bigevent.js` 와 `img/` 를 CDN 기획전 폴더에 (`make` 가 주소를 알려 줌)
3. 게시판 기획전 글에 `index.html` 을 통째로 붙여넣기

- 파일을 다시 올리면 `index.html` 의 `?v=` 숫자를 바꿔요(CDN 이 7일 동안 예전 파일을 줌). `make` 를 다시 돌리면 그날 날짜로 바뀌어요.
- 공통 파일을 고치면 이 파일을 쓰는 **모든 대형 기획전이 같이 바뀌어요.**
- 게시글 번호는 어디에도 적지 않아요. '전 상품 보기' 버튼을 쓰려면 settings 의 `relatedButton.href` 에 그때 주소를 넣어요.

## 공통 파일 다시 만들기 (거의 쓸 일 없음)

완성된 대형 기획전 index.html 을 새 기준으로 삼을 때 :
`python tools/build_engine.py <index.html> <이름>` → `python tools/make_template.py <이름>`
(`samples/<이름>/` 에 기준 설정·글자가 생기고, `be.py` 의 `BASE` 를 그 이름으로 바꾸면 기본값이 바뀜)
