# 【 대형 기획전 타입 】 자동화

기준 = 0914 추석 기획전(2026-09). 모양·기능은 **CDN 공통 파일**, 기획전마다 바뀌는 것은 **설정 파일 + 게시판 붙여넣기 파일**뿐이다.
도구는 이 스킬 폴더의 `be.py` (어느 PC 에서나 같은 경로 : `%USERPROFILE%\Documents\4XR_기획전\.claude\skills\big-event-automation\`).

## 진행 순서 (트리거 받으면)

1. **확인** — 기획전 폴더(사용자가 정한 곳, 예: `기획전_제작\1001_이름` 또는 `E:\작업\콘텐츠\1001_이름`) · 에디터 기획 엑셀('기획파일' 시트, .xls/.xlsx) · 오픈일 · CDN 폴더코드(HSH 등, 사람마다 다름)
2. `python be.py init <폴더> --open YYYY-MM-DD --code HSH` → `img/` 폴더들 · `이미지_목록.md`(설정이 쓰는 이미지 29개 경로·크기) · `대형기획전.json`
3. 엑셀을 폴더에 넣고 `python be.py make <폴더>` → `settings_bigevent.js` + `index.html` (이미 있으면 `_자동생성/`)
   - 보고 = **엑셀에서 읽은 것 · 빠진 섹션 · 확인 필요**(추석 값 그대로인 것). 확인 필요 항목은 사용자에게 물어서 settings 에 반영한다
4. 이미지는 `이미지_목록.md` 경로·이름 그대로 `img/` 에 (크기는 추석 기준)
5. `python be.py check <폴더>` (상품 판매 중 · 데일리 날짜가 기간 안 · 하루 12개 · 이미지) → `python be.py render <폴더> [게시글주소]` (최근 기획전 글에 끼워 PC 1920·모바일 750, 서버에 아직 없는 파일은 로컬로 대신) → `_점검/render_pc.png · render_mo.png`
6. **납품** — CDN 기획전 폴더(`…/연/월/일/폴더코드/`, make 가 안내)에 `settings_bigevent.js` + `img/`, 게시판 기획전 글에 `index.html` 통째. **CDN 먼저 → 게시판 나중**
7. 작업 기록(`기록/<작업자>/…md`) 작성

## 기획 엑셀 읽는 법 (C열 항목 이름으로 섹션을 찾음)

| C열 항목 이름 | 읽는 것 |
|---|---|
| 메인 타이틀 | G칸 첫 줄 = 제목 · `(○○ 기획전)` = 기획전 이름 |
| 서브 타이틀 | T칸 `2026.09.14 - 2026.09.27` = 기간 · `up to 76%` |
| …쿠폰 | X칸 `10% 쿠폰` + Y칸 `…rcoupen.php?idx=868` · G칸 대사 · T칸 `-` 줄 = 유의사항 |
| …예치금 · 상품권 | X칸 상품번호 + Y칸 `[… 상품권] 30만원권 (5%할인)` |
| …럭키백 | X칸 상품번호 · Y칸 이름 · T칸 `59,500원에 판매` |
| H칸이 '날짜' 인 항목 | 순서대로 데일리 특가 1·2 — `날짜 · 상품번호 · 브랜드` 세 칸씩 |
| …후기 | G칸 `기존 1,000원 → 10,000원` · T칸 유의사항 |
| …로또 | G칸 `예치금 100만원` · T칸 유의사항 |
| …가족 · 가입 | 회원 혜택(4XR 공통) |

엑셀에 없는 섹션은 **통째로 뺀다**(스티키 탭·퀵 메뉴·로또 띠까지) — 빈 구좌는 숨기지 않고 없앤다.

## 공통 파일 (처음 한 번 · 고칠 때만)

- `engine/big_event.css` → CDN `…/tgreen09/2026/00/bigevent/css/` · `engine/big_event.js` → `…/2026/00/bigevent/js/`
- 고치면 이 파일을 쓰는 **모든 대형 기획전이 같이 바뀐다.** 다시 올리면 `be.py` 의 `ENGINE_VER` 와 index.html 의 `?v=` 를 바꾼다(CDN 7일 캐시)
- 새 기준 기획전으로 바꿀 때 : `python tools/build_engine.py <완성 index.html> <이름>` → `python tools/make_template.py <이름>` → `be.py` 의 `BASE`

## 지켜야 할 것

- **게시글 번호를 어디에도 적지 않는다** — '전 상품 보기'(settings `relatedButton.href`)는 비워 두고 필요할 때만 그때 주소
- 기존 파일을 덮지 않는다(make 가 `_자동생성/` 에). 엑셀은 읽기만 한다
- 설정은 CDN 에서 불러오는 외부 파일이라 게시판 엔티티 규칙(§7-9) 영향이 없지만, **index.html 안 인라인 스크립트에는 엔티티 리터럴 금지**
- 상품 검색 블록(bf_search, layout 'issue')이 index.html 머리에 들어 있다
- 검증 : 추석 엑셀 → make → render 결과가 실제 추석 페이지와 섹션 높이까지 같음(2026-09-18). 엑셀에 없는 유의사항 줄(추석 페이지에만 있던 것)은 make 가 목록으로 알려 줌
