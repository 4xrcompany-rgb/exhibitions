1) 무엇이 들어가나 기준 = 0914 추석 기획전

  • 메인 비주얼 · 타이머 · 퀵 메뉴 · 스티키 탭 + 쿠폰 · 상품권(예치금) · 럭키백 · 데일리 특가 2개 · 후기 이벤트 · 로또 · 실시간 랭킹 · 회원 혜택 · 상품 검색

이미 파일이 있으면 덮지 않고 _자동생성/ 에 만듭니다.

"점검해줘"

"올렸어" → 확인

# 폴더 만들기 python be.py init <폴더> --open 2026-10-01 --code HSH # 엑셀 → 설정 + index python be.py make <폴더> # 상품 · 날짜 · 이미지 점검 python be.py check <폴더> # PC · 모바일 화면 (주소 없으면 최근 글) python be.py render <폴더> [게시글주소] # check + render python be.py all <폴더>

꼭 확인하세요

  • '확인 필요' 항목은 추석 값 그대로예요 — 비주얼 제목 이미지 위치 · 퀵 메뉴 짧은 이름 · 로또 소개 글 · 후기 작은 글 · 추석 페이지에만 있던 유의사항 줄(고객센터 번호 등).
  • 공통 파일은 첫 대형 기획전 때 한 번 CDN 2026/00/bigevent/ 에 올려요. 고치면 이 파일을 쓰는 모든 대형 기획전이 같이 바뀌어요.
  • 파일을 다시 올리면 index.html 의 ?v= 숫자를 바꿔 다시 붙여넣기 (CDN 7일 캐시). make 를 다시 돌리면 그날 날짜로 바뀌어요.
  • 게시글 번호는 어디에도 적지 않아요. '전 상품 보기' 버튼은 settings 의 relatedButton.href 에 그때 주소를 넣을 때만 나와요.
  • 순서 : CDN 에 먼저 올리고 → 게시판에 붙여넣기. 반대로 하면 잠깐 빈 화면이 나와요.
