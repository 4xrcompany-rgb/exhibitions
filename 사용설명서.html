4XR 기획전 자동화

클로드·피그마를 몰라도
기획전을 만들 수 있는 설명서

폴더 하나 만들고, 채팅으로 몇 마디만 하면 클로드가 기획전 페이지와 배너를 만들어 줍니다. 아래 순서를 그대로 따라 하세요. 파란색은 내가 할 일, 초록색은 클로드가 할 일입니다.

이 설명서는 클로드 앱의 코워크(Cowork) 기준입니다. 가장 중요한 건 2단계 — 새 채팅을 열 때 첫 마디예요. 그것만 빠뜨리지 마세요.

0 처음 한 번만 — 설치

먼저 아래 3가지만 웹에서 받아 더블클릭으로 설치하세요. 명령창(터미널) 쓸 일 없어요.

1
GitHub Desktop — 회사 폴더를 클릭으로 받는 프로그램
desktop.github.com 접속 → Download → 받은 파일 더블클릭 설치. (1단계에서 사용)
2
클로드 데스크톱 앱 — 평소 작업하는 채팅 앱
기획전 작업은 이 앱의 코워크(Cowork)에서 채팅으로 합니다. 설치 후 로그인해 두세요.
  • 꼭 데스크톱 앱이어야 합니다. 웹·모바일에서는 내 컴퓨터 폴더를 못 읽습니다.
3
피그마 계정 (Full seat)
figma.com 가입/로그인. 이미지 규격 레이아웃·소재 작업에 사용. View seat은 편집이 안 됩니다.
📁

Node·Python·엑셀·이미지·배너 도구는 내 컴퓨터에 안 깔아도 됩니다. 코워크에서는 이 작업들을 클로드 쪽 작업공간에서 대신 돌립니다. 내 컴퓨터는 폴더를 보여주는 역할만 해요.

앞으로 모든 작업은 1단계에서 받는 회사 폴더를 코워크에 연결해 두고, 채팅으로 합니다.

1 회사 시스템에 연결 — 내 기록이 자동으로 모이게 (최초 1회)

이걸 해두면 작업할 때마다 내 작업기록·성공·실패·오류를 회사(관리자)에게 전달할 수 있습니다. 처음 한 번만 하면 돼요.

🙋

어렵게 느껴지면 — 이건 ‘처음 한 번’만 하는 설정이에요. 관리자나 컴퓨터를 잘 다루는 사람이 각 컴퓨터에서 한 번만 해주면, 이후 작업자는 채팅만 하면 됩니다.

🎁

먼저 관리자에게 받으세요.

① 회사 GitHub 로그인 정보(또는 관리자가 대신 로그인)　② 저장소 이름/주소　③ 나에게 쓸 이름

⚠️ USB로 폴더만 복사하면 안 돼요. 그러면 회사와 연결이 안 돼서 기록이 안 올라갑니다. 꼭 아래 GitHub Desktop으로 받아야 연결됩니다.

1
GitHub Desktop 로그인
GitHub Desktop 앱 열기 → Sign in to GitHub.com → 브라우저가 열리면 회사 아이디로 로그인 → Authorize 클릭. (관리자가 대신 해줘도 됨)
2
회사 폴더 받기 (클릭)
맨 위 File → Clone repository → 목록에서 회사 저장소를 클릭(또는 주소 붙여넣기) → 받을 위치 고르고 → Clone 버튼. 폴더가 알아서 받아집니다.
3
코워크에 폴더 연결
클로드 데스크톱 앱 → 코워크 → “폴더 추가(Add folder)” → 방금 받은 회사 폴더를 선택합니다.
  • 연결해 두면 클로드가 그 폴더 안의 파일을 읽고 쓸 수 있습니다.
  • ⚠️ 폴더 연결은 채팅을 시작할 때 정해집니다. 작업 도중에는 폴더를 추가할 수 없으니, 시작 전에 연결해 두세요.
  • 준비물 설치(_처음설치_한번만 폴더의 .bat 2개)는 코워크에서는 안 해도 됩니다. 클로드 코드로 작업할 때만 필요해요.
4
내 이름 등록
폴더를 연결한 채팅방에서 이렇게 말하면 끝입니다.
내 이름 홍길동으로 WHOAMI 만들어줘
✅

연결 끝! 작업이 끝나면 클로드가 작업기록 파일을 만들어 저장까지 해줍니다.

마지막 전송(올리기)만 내가 눌러요. 코워크에서는 클로드가 회사 서버로 직접 올리지 못합니다 — 작업이 끝나면 클로드가 “이제 올려주세요”라고 알려주는데, 그때 GitHub Desktop을 열고 Commit → Push origin(또는 옵시디언의 동기화 버튼) 한 번만 눌러주세요. 클릭 한 번입니다.

가끔 회사 최신 개선을 받고 싶으면 GitHub Desktop 위쪽의 “Fetch origin / Pull” 한 번 누르면 됩니다.

2 새 채팅을 열 때 — 첫 마디 ★가장 중요

새 채팅방을 열 때마다 아래 3가지를 하세요. 특히 ③번을 빠뜨리면 클로드가 회사 규칙을 모르는 채로 작업합니다.

1
폴더가 연결돼 있는지 확인
채팅 시작 화면에서 회사 폴더가 연결돼 있어야 합니다. 안 돼 있으면 “폴더 추가”로 지금 연결하세요.
  • 시작한 뒤에는 폴더를 추가할 수 없습니다. 빠뜨렸으면 채팅을 새로 여는 게 빠릅니다.
2
모드를 ‘자동’으로
채팅창 아래쪽에서 모드를 ‘자동’으로 바꿔 주세요. 매번 “해도 되나요?”를 안 묻습니다. 권한을 물으면 “항상 허용”을 누르면 그다음부터 안 물어봅니다.
3
첫 마디로 ‘규칙 읽어줘’ 라고 말하기 ★
아래 문장을 그대로 복사해서 첫 메시지로 보내세요.
새 채팅 첫 메시지 — 그대로 복사
기획전 작업 규칙 먼저 읽고 시작해줘.
CLAUDE.md 랑 .claude/skills/gihoekjeon-automation-system/SKILL.md 읽어줘.
클로드가 “규칙 읽었습니다” + 지금 폴더가 몇 단계인지 알려주면 준비 완료입니다. 그 뒤에 하고 싶은 일을 말하세요.
❓

왜 이걸 해야 하나요?

회사 작업 규칙(엑셀 덮어쓰기 금지, 디자인 임의 변경 금지, 작업 순서 등)은 폴더 안에 파일로 들어 있습니다. 코워크는 이 파일을 자동으로 읽지 않습니다. 그래서 첫 마디로 알려줘야 해요.

안 알려주면 클로드가 구성표 엑셀을 새로 만들어 덮어쓰거나, 디자인을 마음대로 바꾸는 사고가 납니다. 실제로 났던 사고들입니다.

채팅방마다 한 번씩이면 됩니다. 같은 채팅방 안에서는 다시 말할 필요 없어요.

3 작업 순서

위에서 아래로 그대로 따라 하세요. 검은 칸은 채팅에 그대로 입력하는 말입니다. 2단계(첫 마디)를 먼저 한 뒤에 시작합니다.

내가 할 일 클로드가 할 일
1
나
새 폴더를 만들고, 기획전 엑셀(기획서)을 그 안에 넣기
예: 기획전_제작 / 0707_셀렉샵 바캉스 폴더 안에 받은 엑셀을 넣습니다.
2
나
어느 기획전인지 말하고 시작 요청하기
폴더는 이미 연결돼 있으니 경로를 붙여넣을 필요 없습니다. 기획전 폴더 이름만 말하면 됩니다.
0707_셀렉샵 바캉스 기획전 작업 시작
  • 폴더 이름이 헷갈리면 “기획전_제작 폴더에 뭐 있어?” 라고 물어보면 목록을 보여줍니다.
3
클로드
“참고 시안 링크를 알려주세요” 라고 물어봄
따라 만들 기획전(벤치마크) 링크를 채팅에 붙여넣어 주세요.
4
클로드
참고 디자인을 PC·모바일 똑같이 만들어 보여줌
보고 고칠 곳이 있으면 말해 주세요. 괜찮으면 다음으로 넘어갑니다. (디자인만 재현 — 사진·상품은 뒤에서 채웁니다.)
5
클로드
구성표 엑셀 · 소재 폴더 · 피그마 규격 레이아웃을 자동 생성
이미지를 넣을 점선 규격 칸이 있는 피그마와, 채울 구성표 엑셀이 만들어집니다.
6
나
구성표 엑셀 채우기 + 피그마 규격 칸에 이미지 넣기
① 구성표 엑셀에 내용을 채우고 ② 피그마의 점선 칸(또는 소재 폴더)에 이미지를 넣습니다.
7
나
다 되면 채팅으로 알려주기
엑셀·폴더를 손봤으면 반영을, 피그마에서 크기·위치를 다 맞췄으면 저장을 요청합니다.
엑셀 수정하고 폴더에 이미지 넣었어피그마 이미지 내보내기
8
나
엑셀 내용으로 기획전을 만들라고 말하기
클로드가 엑셀을 읽어 기획전 페이지를 완성합니다. 이때 상품 진열 방법을 먼저 물어봅니다 — 대답만 해주면 됩니다.
  • 어느 탭까지 자동 연결할까요? — 엑셀의 상품 탭 중 기획전에 자동으로 진열할 탭을 알려주세요. (상품코드만 있으면 이미지·가격·링크를 클로드가 몰에서 자동으로 불러옵니다.)
  • 어느 탭은 직접 진열하나요? — 사이트(비즈호스트)에서 본인이 직접 상품을 넣을 탭이 있으면 알려주세요. 그 탭은 클로드가 건드리지 않습니다.
  • 예: “큐레이션 탭만 자동 연결, 나머지는 내가 직접 진열할게.”
엑셀 적용
9
나
완성 이미지를 FTP에 올리고, 폴더명 알려주기
클로드가 알려주는 파일명 그대로 FTP에 올린 뒤, 만든 폴더명을 채팅에 말하면 페이지에 이미지 주소를 연결해 줍니다.
  • 폴더 규칙 — 고정 주소 …/tgreen09/ 뒤에 년 / 월 / 일 / 작업자 순서로 폴더를 만듭니다.
  • 예시 — 2026/08/07/SOL = 2026년 8월 7일, 작업자 SOL. (작업자는 본인 이니셜)
  • 그러면 이미지 주소는 …/tgreen09/2026/08/07/SOL/파일명.jpg 가 됩니다.
  • 채팅엔 이 폴더명만 알려주면 됩니다 — 예: 2026/08/07/SOL
10
나
디자인 확정하기
기획전이 마음에 들면 확정을 말합니다. 이 말을 해야 배너 단계로 넘어갑니다. (아직 고칠 게 있으면 먼저 다 고친 뒤에 말하세요.)
기획전 디자인 끝
💡

고칠 땐 이렇게 — 빠르고 저렴하게

고쳐달라고 할 때 말하는 방법에 따라 걸리는 시간(비용)이 크게 달라집니다. 아래처럼 하면 최소한으로 바뀝니다.

  • 콕 집어서 — “전체 다시”가 아니라 바꿀 곳만. 예: “2번째 섹션 제목만 XX로.”
  • 위치를 정확히 — 어느 섹션의 무엇인지 짚어주세요. 화면 캡처에 표시해서 주면 가장 정확합니다.
  • 바꿀 값만 — 색은 색만, 문구는 문구만, 간격은 간격만. 한 번에 하나씩.
  • 여러 군데면 한 번에 — 고칠 곳을 목록으로 모아 한 번에 말하면 왕복이 줄어 더 빠릅니다.
  • 피해야 할 말 — “알아서 예쁘게”, “전체 갈아엎어줘” (전부 다시 만들어 오래 걸립니다).
11
나
배너 만들기
배너를 요청하면 클로드가 먼저 두 가지를 물어봅니다 — 대답에 맞춰 배너 7종(PC배너·모바일배너·썸네일·카톡푸시·앱푸시 3종)의 초안을 만듭니다.
  • ① 참고할 예시가 있나요? — 원하는 배너 느낌의 예시 이미지가 있으면 폴더에 넣거나 채팅에 올려주세요.
  • ② 아니면 기획전 상단(KV)처럼 갈까요? — 예시가 없으면 기획전 맨 위 메인 이미지 분위기를 기준으로 만듭니다.
배너 만들어줘
🎨

배너 수정은 ‘피그마’에서 합니다

배너 초안이 나오면, 세부 수정(문구·색·이미지 위치)은 피그마로 이동해서 직접 다듬습니다.

  • 어디서? — 피그마에 만들어진 배너 레이아웃(프레임)에서 글자·색·이미지를 바꿉니다.
  • 다 되면 — 채팅에 피그마 이미지 내보내기 라고 말하면 클로드가 JPG로 저장해 줍니다. (기획전 이미지 내보낼 때와 같은 방법)
12
나
마무리 — 작업기록 올리기 (클릭 한 번)
작업이 끝나면 클로드가 작업기록 파일을 만들어 폴더에 저장하고 “이제 올려주세요”라고 알려줍니다.
  • GitHub Desktop을 열고 → Commit → Push origin 클릭. (또는 옵시디언의 동기화 버튼)
  • 이걸 눌러야 회사(관리자)에게 기록이 전달돼서 시스템이 개선됩니다.

5 막히면

자주 나오는 상황과 해결법.

엑셀이 안 읽혀요
엑셀이 열려 있으면 못 읽습니다. 엑셀을 닫고 다시 요청하세요.
기획전을 열었는데 상품이 안 보여요
정상입니다. 상품은 몰(게시판)에 올려야 실시간으로 뜹니다. 내 컴퓨터에서 열면 상품 자리만 보입니다.
피그마 편집이 안 돼요
