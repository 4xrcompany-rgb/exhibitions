4XR 기획전 자동화

클로드·피그마를 몰라도
기획전을 만들 수 있는 설명서

폴더 하나 만들고, 채팅으로 몇 마디만 하면 클로드가 기획전 페이지와 배너를 만들어 줍니다. 아래 순서를 그대로 따라 하세요. 파란색은 내가 할 일, 초록색은 클로드가 할 일입니다.

0 처음 한 번만 — 설치

컴퓨터에 아래 6가지를 깔아 둡니다. 한 번 하면 다음부터는 안 해도 됩니다.

✓
Node.js (18 이상)
터미널에 node -v 쳐서 버전이 나오면 설치된 것.
✓
Python (3.10 이상)
python --version 으로 확인.
✓
클로드 코드
npm install -g @anthropic-ai/claude-code
✓
파이썬 패키지 (엑셀·이미지 처리)
pip install openpyxl pillow requests beautifulsoup4
✓
배너 캡처용 브라우저
npm install playwright 그다음 npx playwright install chromium
✓
피그마 계정 (Full seat)
이미지 규격 레이아웃·소재 작업에 사용. View seat은 편집이 안 됩니다.
📁

자동화 폴더를 받아서, 그 폴더 안에서 클로드 코드를 켭니다.

처음 켜면 “이 폴더를 신뢰하시겠습니까?”를 물어봐요 → 예를 눌러야 자동화가 켜집니다.

1 회사 시스템에 연결 — 내 기록이 자동으로 모이게 (최초 1회)

이걸 해두면 작업할 때마다 내 작업기록·성공·실패·오류가 회사(관리자)에게 자동 전송됩니다. 처음 한 번만 하면 돼요.

🎁

먼저 관리자에게 3가지를 받으세요.

① 저장소 주소　② 접속 토큰(github_pat_… 로 시작하는 긴 문자열)　③ 나에게 쓸 이름

1
Git 설치 (폴더를 받아오는 프로그램)
git-scm.com 접속 → 다운로드 → 설치(전부 ‘Next’). 한 번만 하면 됩니다.
2
작업 폴더 받아오기
터미널에 git clone [관리자가 준 주소] 입력 → 창이 뜨면 Username = 회사 아이디, Password = 받은 토큰 붙여넣기. (비밀번호 아니라 토큰!) 받아진 폴더가 앞으로 작업할 폴더입니다.
3
내 이름 등록
그 폴더에서 클로드 코드를 켜고 이렇게 말하면 끝입니다.
내 이름 홍길동으로 WHOAMI 만들어줘
✅

연결 끝! 이제 평소처럼 작업하면 기록이 자동으로 전송됩니다. 따로 올리는 버튼 같은 건 없어요 — 클로드가 알아서 합니다.

📓 (선택) 옵시디언 — 내 기록·개선사항을 눈으로 보고 싶을 때

위 3단계로 기록 전송은 이미 됩니다. 옵시디언은 안 깔아도 돼요. 대시보드·개선사항을 직접 보고 싶은 사람만 하세요.

✓
옵시디언 설치
obsidian.md 접속 → Download → 설치.
✓
받은 폴더 열기
첫 화면 “폴더를 보관함으로 열기” → 2번에서 받아온 폴더 선택 → “제작자를 신뢰…” 창이 뜨면 클릭. (화면이 영어면 설정 → 일반 → 언어 → 한국어)
✓
플러그인 2개 설치
설정(⚙) → 커뮤니티 플러그인 켜기 → 둘러보기 → “Git”(개발자 Vinzent) 설치·활성화, “Dataview” 설치·활성화.
✓
‘받기’만 켜기 (Git 플러그인)
설정 → Git → Auto pull interval (minutes) 에 10 입력. ⚠️ Auto commit·sync 류는 켜지 마세요 — 기록은 클로드가 알아서 올립니다.
✓
대시보드 열기
왼쪽 파일 목록 → ★건들지마세요(시스템) → 00_대시보드.md

2 시작 전 — 채팅방을 ‘자동’ 모드로

이걸 켜면 클로드가 매번 “해도 되나요?”를 안 묻고 알아서 파일을 만들고 고칩니다.

⚙️

채팅창 아래쪽에서 모드를 ‘자동’으로 바꿔 주세요.

작업 중 권한을 물으면 “항상 허용”을 누르면 그다음부터 안 물어봅니다.

3 작업 순서

위에서 아래로 그대로 따라 하세요. 검은 칸은 채팅에 그대로 입력하는 말입니다.

내가 할 일 클로드가 할 일
1
나
새 폴더를 만들고, 기획전 엑셀(기획서)을 그 안에 넣기
예: 기획전_제작 / 0707_셀렉샵 바캉스 폴더 안에 받은 엑셀을 넣습니다.
2
나
채팅에 폴더 경로를 붙여넣고, 시작이라고 말하기
폴더 경로를 복사해 붙여넣고, 다음 줄에 아래를 입력합니다. 권한을 물으면 항상 허용.
기획전 작업 시작
3
클로드
“참고 시안 링크를 알려주세요” 라고 물어봄
따라 만들 기획전(벤치마크) 링크를 채팅에 붙여넣어 주세요.
4
클로드
참고 디자인을 PC·모바일 똑같이 만들어 보여줌
보고 고칠 곳이 있으면 말해 주세요. 괜찮으면 다음으로 넘어갑니다. (디자인만 재현 — 사진·상품은 뒤에서 채웁니다.)
5
클로드
구성표 엑셀 · 소재 폴더 · 피그마 규격 레이아웃을 자동 생성
이미지를 넣을 점선 규격 칸이 있는 피그마와, 채울 구성표 엑셀이 만들어집니다.
6
나
구성표 엑셀 채우기 + 피그마 규격 칸에 이미지 넣기
① 구성표 엑셀에 내용을 채우고 ② 피그마의 점선 칸(또는 소재 폴더)에 이미지를 넣습니다.
7
나
다 되면 채팅으로 알려주기
엑셀·폴더를 손봤으면 반영을, 피그마에서 크기·위치를 다 맞췄으면 저장을 요청합니다.
엑셀 수정하고 폴더에 이미지 넣었어피그마 이미지 내보내기
8
나
엑셀 내용으로 기획전을 만들라고 말하기
클로드가 엑셀을 읽어 기획전 페이지를 완성합니다. 이때 상품 진열 방법을 먼저 물어봅니다 — 대답만 해주면 됩니다.
  • 어느 탭까지 자동 연결할까요? — 엑셀의 상품 탭 중 기획전에 자동으로 진열할 탭을 알려주세요. (상품코드만 있으면 이미지·가격·링크를 클로드가 몰에서 자동으로 불러옵니다.)
  • 어느 탭은 직접 진열하나요? — 사이트(비즈호스트)에서 본인이 직접 상품을 넣을 탭이 있으면 알려주세요. 그 탭은 클로드가 건드리지 않습니다.
  • 예: “큐레이션 탭만 자동 연결, 나머지는 내가 직접 진열할게.”
엑셀 적용
9
나
완성 이미지를 FTP에 올리고, 폴더명 알려주기
클로드가 알려주는 파일명 그대로 FTP에 올린 뒤, 만든 폴더명을 채팅에 말하면 페이지에 이미지 주소를 연결해 줍니다.
  • 폴더 규칙 — 고정 주소 …/tgreen09/ 뒤에 년 / 월 / 일 / 작업자 순서로 폴더를 만듭니다.
  • 예시 — 2026/08/07/SOL = 2026년 8월 7일, 작업자 SOL. (작업자는 본인 이니셜)
  • 그러면 이미지 주소는 …/tgreen09/2026/08/07/SOL/파일명.jpg 가 됩니다.
  • 채팅엔 이 폴더명만 알려주면 됩니다 — 예: 2026/08/07/SOL
10
나
디자인 확정하기
기획전이 마음에 들면 확정을 말합니다. 이 말을 해야 배너 단계로 넘어갑니다. (아직 고칠 게 있으면 먼저 다 고친 뒤에 말하세요.)
기획전 디자인 끝
💡

고칠 땐 이렇게 — 빠르고 저렴하게

고쳐달라고 할 때 말하는 방법에 따라 걸리는 시간(비용)이 크게 달라집니다. 아래처럼 하면 최소한으로 바뀝니다.

  • 콕 집어서 — “전체 다시”가 아니라 바꿀 곳만. 예: “2번째 섹션 제목만 XX로.”
  • 위치를 정확히 — 어느 섹션의 무엇인지 짚어주세요. 화면 캡처에 표시해서 주면 가장 정확합니다.
  • 바꿀 값만 — 색은 색만, 문구는 문구만, 간격은 간격만. 한 번에 하나씩.
  • 여러 군데면 한 번에 — 고칠 곳을 목록으로 모아 한 번에 말하면 왕복이 줄어 더 빠릅니다.
  • 피해야 할 말 — “알아서 예쁘게”, “전체 갈아엎어줘” (전부 다시 만들어 오래 걸립니다).
11
나
배너 만들기
배너를 요청하면 클로드가 먼저 두 가지를 물어봅니다 — 대답에 맞춰 배너 7종(PC배너·모바일배너·썸네일·카톡푸시·앱푸시 3종)의 초안을 만듭니다.
  • ① 참고할 예시가 있나요? — 원하는 배너 느낌의 예시 이미지가 있으면 폴더에 넣거나 채팅에 올려주세요.
  • ② 아니면 기획전 상단(KV)처럼 갈까요? — 예시가 없으면 기획전 맨 위 메인 이미지 분위기를 기준으로 만듭니다.
배너 만들어줘
🎨

배너 수정은 ‘피그마’에서 합니다

배너 초안이 나오면, 세부 수정(문구·색·이미지 위치)은 피그마로 이동해서 직접 다듬습니다.

  • 어디서? — 피그마에 만들어진 배너 레이아웃(프레임)에서 글자·색·이미지를 바꿉니다.
  • 다 되면 — 채팅에 피그마 이미지 내보내기 라고 말하면 클로드가 JPG로 저장해 줍니다. (기획전 이미지 내보낼 때와 같은 방법)

5 막히면

자주 나오는 상황과 해결법.

엑셀이 안 읽혀요
엑셀이 열려 있으면 못 읽습니다. 엑셀을 닫고 다시 요청하세요.
기획전을 열었는데 상품이 안 보여요
정상입니다. 상품은 몰(게시판)에 올려야 실시간으로 뜹니다. 내 컴퓨터에서 열면 상품 자리만 보입니다.
피그마 편집이 안 돼요
View seat으로 로그인된 상태입니다. Full seat 계정으로 다시 로그인하세요.
배너 캡처가 안 돼요
터미널에 npx playwright install chromium 를 한 번 더 실행하세요.
한 문장 요약 — 폴더에 엑셀 넣기 → 「기획전 작업 시작」 → 참고 링크 → 확인 → 엑셀·이미지 채우기 → 「엑셀 적용」 → 「기획전 디자인 끝」 → 「배너 만들어줘」.
