이 폴더는 "처음 한 번만" 쓰는 자동 설치 폴더입니다.

순서 (위에서 아래로, 더블클릭만):

  ★ 코워크(Cowork)에서만 작업한다면 → 1), 2) 는 건너뛰고 3) 만 하세요.
     클로드 코드로도 작업한다면 1) 부터 차례로 하세요.

  1) ➊_프로그램설치.bat  더블클릭
     - "예" 를 한 번 눌러 권한을 허용하세요.
     - Node.js / Python / Git 이 자동으로 깔립니다.
     - "끝!" 이 나오면 창을 닫으세요.

  2) ➋_도구설치.bat  더블클릭
     - 엑셀 / 이미지 / 배너 도구가 자동으로 깔립니다.
     - "설치 끝!" 이 나오면 창을 닫으세요.

  3) ➌_자동기록동기화.bat  더블클릭       ← 꼭 하세요
     - 작업기록이 회사로 "자동으로" 올라가게 만듭니다.
     - 30분마다 알아서 올라갑니다. GitHub Desktop 을 열 필요가 없어집니다.
     - 마지막에 "설정 끝!" 이 나오면 창을 닫으세요.
     - 옵시디언이 켜져 있었다면 껐다 켜 주세요.

혹시 ➋에서 "Node.js 가 안 잡힌다" 고 나오면,
컴퓨터를 한 번 재시작한 뒤 ➋를 다시 더블클릭하세요.

자동 동기화를 끄고 싶으면 ➍_자동동기화_해제.bat 를 더블클릭하세요.

설치가 끝나면 이 폴더는 다시 열 일이 없습니다.
